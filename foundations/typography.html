Typography

타이포그래피는 텍스트를 읽기 쉽고 아름답게 표현하는 시각적 체계로, 폰트 선택 · 크기 · 굵기 · 행간 · 자간을 조합하여 정보의 위계와 가독성을 만들어냅니다. Pretendard 서체 하나로 타이틀 · 본문 · 숫자 · 캡션의 크기와 굵기 차이를 분명히 두어 위계를 만들고, 각 단계를 텍스트 스타일 클래스로 제공합니다.

Basic typography

한국어와 영어를 함께 쓰는 관리 콘솔의 기본 글꼴로 Pretendard 를 사용합니다. 가변 서체 하나로 Regular 400 · Medium 500 · SemiBold 600 · Bold 700 을 모두 표현합니다. 숫자는 자릿수가 바뀌어도 폭이 같은 숫자 글꼴로 써서 표와 KPI 의 정렬을 유지합니다.

일본어도 지원합니다. Pretendard 에는 가나는 있지만 한자가 없어서, 서체 순서에서 Pretendard 바로 뒤에 Pretendard JP 를 둡니다. 한글 · 라틴 · 가나는 Pretendard 가, 한자만 Pretendard JP 가 그립니다. Pretendard JP 는 글자 범위별 조각 119개로 되어 있습니다. 한자가 화면에 나올 때만 해당 조각을 내려받고, 한자가 없는 화면은 하나도 받지 않습니다. 일본어를 쓰는 제품만 일본어 서체 파일을 더합니다. 한자는 일본식 자형이라 한국어 문장 속 한자도 그 모양이 됩니다. 한국식 자형이 필요한 자리에는 서체의 한국식 자형 옵션을 켭니다.

Word break

개발 시 본문 · 표 · 설명 텍스트는 브라우저 기본값대로 음절 단위로 줄바꿈됩니다. 따라서 디자인에서 별도로 줄바꿈 위치를 지정하지 않아도 되고, 폭이 좁은 셀에서도 넘치지 않습니다. 제목 · 알림 · 빈 화면 문구처럼 짧고 눈에 띄는 문장만 단어 단위로 줄을 바꿉니다.

Style

Figma Text Style 이름과 1:1 인 19단계입니다. 스타일은 크기 · 행간 · 자간을 정하고, 굵기는 아래 Weight 의 클래스로 고릅니다. 클래스를 붙이지 않으면 표의 기본 굵기입니다. 자간은 Pretendard 권장값(크기가 작을수록 넓게)을 따르고, 행간은 고정값으로 두어 컴포넌트 높이를 예측할 수 있게 합니다. Body · Label 1 의 Normal 은 한 줄 UI 글자, Reading 은 여러 줄로 읽는 글입니다. 표의 크기 · 행간은 루트가 16px 인 기준 화면의 값이고, CSS 는 같은 값을 rem 으로 적습니다. 숫자에는 숫자 클래스를 함께 씁니다. 클래스를 누르면 복사됩니다.

Size units

글자 · 간격 · 높이는 rem 으로 적습니다. rem 은 페이지 루트의 글꼴 크기를 기준으로 하므로, 화면 폭에 따라 루트 크기를 한 단계 바꾸면 화면 전체가 같은 비율로 커지거나 줄어듭니다. 기준 화면의 루트는 16px 이라 Figma 의 px 수치와 같습니다. 루트를 % 로 적어 사용자가 브라우저 글꼴 크기를 바꾸면 그것도 따릅니다.

  • 최소 글자 크기 — 좁은 화면에서 12px 이 11.25 · 11px 이 10.3 이 되면 한글이 읽기 어려워 12 이하 글자와 그 행간은 줄이지 않습니다.
  • em 은 크기 단위로 쓰지 않습니다 — 부모 크기를 곱해 중첩될수록 값이 커지거나 작아집니다. 자간처럼 글자 크기를 따라가야 하는 값과 인라인 코드에만 씁니다.
  • px 로 남기는 것 — 테두리 · 외곽선 두께, 그림자, 2px 이하. 소수 px 에서 선이 흐려지지 않게 합니다.
  • 글자 크기는 토큰으로 — 컴포넌트의 글자 크기는 글자 크기 토큰만 씁니다. 탐색형 차트도 화면 폭 단계의 비율을 곱해 그립니다.
  • React — 패키지도 rem 이라 제품 페이지 루트의 글꼴 크기를 따릅니다. 화면 폭 단계는 패키지의 단계 파일을 불러올 때만 켜집니다. 제품이 루트 글꼴 크기를 62.5% 처럼 줄여 두면 화면 전체가 작아집니다.
