InteractionN

여러 컴포넌트에 걸친 동작 규칙입니다. 컴포넌트마다 따로 정하면 어긋나는 것을 여기에 한 번 쓰고, 각 컴포넌트는 이 규칙을 따릅니다.

지금 칸은 현재 코드의 상태입니다. 적용은 이미 들어가 있다는 뜻이고, 아직은 규칙만 정했고 적힌 컴포넌트를 정비할 때 고친다는 뜻입니다. 제품은 시스템이 대신할 수 없어 제품 화면을 만들 때 지키는 규칙입니다.

Disabled

비활성 버튼은 포커스를 받지 못해 왜 누를 수 없는지 알 방법이 없습니다. 그래서 언제 비활성으로 두는지를 정합니다. 색은 --surface-disable-primary · --foreground-disable-primary 로 칠합니다.

규칙지금
폼 제출 버튼은 비활성으로 두지 않습니다. 누르면 검증하고 오류로 안내합니다적용 — 패턴 예제의 주 버튼은 빌드가, 약관 동의의 '다음' 은 동작 검사가 봅니다
권한이나 상태 때문에 할 수 없는 동작은 비활성으로 두고 이유를 화면에 적습니다아직 — Card 선택 카드만 이유 줄이 있습니다. 나머지는 각 컴포넌트 정비 때
권한이 아예 없는 메뉴는 숨깁니다제품
비활성 요소에 Tooltip 을 달지 않습니다적용 — 예제를 빌드가 검사합니다
예외: 바뀐 것이 없어 누를 일이 없는 오버레이 안 '적용'(Date Picker), 확인 문구를 입력해야 풀리는 위험 실행 버튼(Popup)은 비활성으로 둡니다적용

Input errors

오류 문구를 쓰는 법은 Writing 에 있습니다. 여기서는 언제 보여 주고 언제 지우는지를 정합니다.

규칙지금
포커스가 떠날 때 필드 단위로 검증합니다. 건드리지 않은 빈 필드는 제출할 때 알립니다적용 — 입력 폼의 data-validate, 동작 검사가 있습니다
제출하면 첫 오류로 스크롤하고, 오류가 3개 이상이면 폼 위에 요약합니다적용 — 동작 검사가 있습니다
입력을 고치면 오류를 바로 지웁니다적용 — 동작 검사가 있습니다
오류가 나도 입력값을 지우지 않습니다적용 — 동작 검사가 있습니다
오류 문구 영역은 aria-live="polite" 로 알립니다적용 — data-validate · data-maxlength 필드, 속성을 검사합니다
Select · Checkbox 그룹 · Radio 그룹도 오류 상태를 가집니다적용 — Select · Combobox · Checkbox · Radio Button · File Upload
자주 나는 오류 문구는 사전으로 모아 기본값으로 씁니다아직 — 검증 기본 문구와 Date Picker의 messages 가 따로 있습니다

Overlays

Popup · Dropdown · Select · Date Picker · Tooltip · Toast 가 함께 지키는 규칙입니다.

규칙지금
모달 위에 모달을 띄우지 않습니다적용 — Popup: 사이트는 막고 경고, React 는 경고
Esc 는 가장 안쪽 것 하나만 닫습니다. Popup 안의 Select 가 열려 있으면 Select 만 닫습니다적용 — Select · Dropdown · Combobox · Date Picker · Tooltip
입력 중이거나 위험 확인이면 배경을 눌러도 닫지 않습니다적용 — Popup, 동작 검사가 있습니다
열면 포커스를 안으로 옮기고, 닫으면 연 요소로 돌려보냅니다적용 — Popup · Side Panel, 동작 검사가 있습니다
Toast 는 모달 위에 보입니다적용 — Toast 110, 배경 100
overflow 안에 있어도 작은 오버레이가 잘리지 않습니다적용 — Dropdown · Select · Combobox · Tooltip

Destructive actions

되돌릴 수 있는지에 따라 확인 단계를 고릅니다. 모두 확인받으면 습관적으로 넘기게 됩니다.

영향흐름
되돌릴 수 있음바로 실행 → Toast 와 실행 취소
되돌리기 어려움Popup 확인 → 실행 → 결과 알림
복구할 수 없고 대량Popup 에 대상 수 표시 + 확인 문구 입력 → 실행 → 결과 알림
규칙지금
위험 확인의 첫 포커스는 취소에 둡니다. 확인 문구를 입력하는 대화상자는 입력칸에 둡니다적용 — Popup은 닫기(X)와 위험 실행 버튼을 건너뜁니다. 동작 검사가 있습니다
보안 기능을 끄는 Switch 도 이 표를 따릅니다제품 — Switch 의 응답 후 반영(ds:switch · action) 안에서 확인을 띄웁니다

Overflow

규칙지금
말줄임은 마지막 수단입니다. 먼저 줄바꿈이나 폭 조정을 씁니다제품
줄인 글자는 키보드로도 전체를 볼 수 있어야 합니다. title 속성은 키보드로 볼 수 없습니다적용 — Breadcrumb 의 잘린 항목, Data Table 의 말줄임 칸, Navigation 의 접힌 메뉴는 Tooltip 을 씁니다
포커스를 받을 수 없는 요소(Tag 등)는 말줄임이 필요 없게 길이를 제한합니다적용 — Tag 는 최대 폭 160 에서 자르지 않고 줄바꿈합니다
