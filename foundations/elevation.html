Elevation

Elevation 은 Z축을 기준으로 두 표면 사이의 거리를 나타내는 시각적 체계입니다. 그림자와 배경 명도 차이를 조합하여 UI 컴포넌트 간의 깊이감과 시각적 계층을 만듭니다. 구획은 1px 보더를 겹치는 대신 배경 차이와 아주 부드러운 그림자로 만들어, 밀도가 높은 콘솔 화면에서도 정돈된 구조를 전달합니다.

Composition

더 자연스럽고 현실과 유사한 깊이감을 표현하기 위해 물체 주변으로 은은하게 퍼지는 주변광 그림자(Ambient shadow)와 특정 방향의 조명에 의해 생기는 뚜렷한 직사광 그림자(Key shadow)를 레이어링하여 구성합니다. 값이 두 겹인 이유입니다.

--shadow-1 · 2 · 3 은 각각 Small · Medium · XLarge 의 별칭으로, 기존 컴포넌트 CSS 와 호환됩니다. 배경 음영(Dimmer)은 Colors › Material 을 참고하세요.

CSS

:root {
  --shadow-none: none;
  --shadow-xs: 0 1px 2px 0 rgba(15,23,42,.04);
  --shadow-sm: 0 1px 3px 0 rgba(0,0,0,.05);
  --shadow-md: 0 4px 12px 0 rgba(15,23,42,.06),0 1px 3px 0 rgba(0,0,0,.05);
  --shadow-lg: 0 8px 24px 0 rgba(15,23,42,.08),0 2px 6px 0 rgba(0,0,0,.05);
  --shadow-xl: 0 12px 32px 0 rgba(15,23,42,.10),0 2px 6px 0 rgba(0,0,0,.05);
  --shadow-spread-sm: 0 0 8px 0 rgba(15,23,42,.08);
  --shadow-spread-md: 0 0 24px 0 rgba(15,23,42,.12);
  --shadow-1: var(--shadow-sm);
  --shadow-2: var(--shadow-md);
  --shadow-3: var(--shadow-xl);
}
