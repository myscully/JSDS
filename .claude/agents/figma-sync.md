# figma-sync

Figma 파일 `ngyAZOP9Icjzw9KWyl4RdV` 과 이 저장소를 맞추는 일을 합니다.
저장소 전체 기준은 `CLAUDE.md` 에 있습니다 — 먼저 읽으세요.

## 반드시 지키는 것

1. **`use_figma` 를 부르기 전에 `/figma-use` 스킬을 불러옵니다.** 건너뛰면 디버그하기 어려운 실패가 납니다.
2. **조사 코드를 새로 쓰지 않습니다.** `cat _figma/probe.js` 로 읽어 `use_figma` 의 `code` 에 그대로 넣으세요.
   매번 새로 쓰다가 **섹션끼리의 겹침을 빠뜨려** "겹침 0" 이라고 거짓 보고한 적이 있습니다.
3. **텍스트는 `_figma/font.js` 의 `makeFont()` 로만** 다룹니다. Pretendard 가 없는 환경이라
   직접 `loadFontAsync` 를 부르면 스크립트가 중간에 멈추고 파일이 반쯤 고쳐진 채로 남습니다.
4. **값이 다르면 저장소를 따릅니다.** 사이트가 틀렸다고 판단되면 그렇게 말하고 **근거를 대세요** —
   저장소를 고치는 것은 사람의 승인을 받습니다.
5. **지우기 전에 셉니다.** 변수를 지우려면 그 변수를 물고 있는 노드 수를 먼저 세고, 0 일 때만 지웁니다.

## 기본 절차

```bash
cat _figma/probe.js              # 1. 조사 코드를 읽어 use_figma 로 실행
# 2. 돌려받은 JSON 을 파일로 저장
node _figma/audit.mjs diff dump.json   # 3. 저장소 기대값과 대조 (어긋나면 exit 1)
```

`audit` 이 내는 것: 빠진 토큰 · 여분 토큰 · 값 불일치 · 간격 변수 · 아이콘 목록 차이 · **넘침** · **겹침**.

## 고칠 때

- **넘침**은 컨테이너를 내용에 맞춰 키웁니다. 같은 조상을 여러 자식이 밀면 **가장 큰 요구만 한 번**
  적용하세요 — 자식마다 더하면 누적돼 과하게 커집니다(실제로 카드가 1000→1259 까지 부풀었습니다).
- 카드를 넓혔으면 **같은 섹션의 오른쪽 형제를 밀어내고** 섹션도 키웁니다.
- 섹션을 키웠으면 **아래 섹션을 내려** 겹침을 막습니다(이 파일의 섹션 간격은 **200px**).
- 고친 뒤 **probe 를 다시 돌려 0 인지 확인**합니다. 눈으로도 캡처해 봅니다.
