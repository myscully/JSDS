설정

내 계정의 정보를 보고 고치는 설정 화면입니다. 왼쪽 설정 메뉴에서 항목을 고르고, 오른쪽 카드마다 편집을 눌러 패널에서 바꿉니다.

언제 쓰는가
한 사람이나 한 대상의 정보를 묶음별 카드로 보여 주고, 묶음 단위로 고치게 할 때 씁니다.
비슷한 템플릿
여러 설정 값을 한 화면에서 켜고 끄며 바로 바꾸면 정책 설정입니다.

Preview

실제 화면을 줄여 보여 줍니다. 안의 버튼과 메뉴도 동작합니다. 코드 보기를 누르면 화면 전체의 HTML 과 앱 틀 배치 CSS 를 볼 수 있습니다. 컴포넌트 모양은 사이트 스타일시트가 맡습니다.

Rules

두 칸
왼쪽에 설정 메뉴, 오른쪽에 고른 메뉴의 내용을 둡니다. 설정 메뉴는 아이콘 없이 이름만 적고, 지금 보는 항목을 표시합니다.
카드
정보는 묶음마다 카드 하나로 나누고, 카드 머리에 그 묶음의 편집 버튼을 하나 둡니다.
두 줄 값
카드 안 정보는 두 칸으로 나눠 라벨을 위에, 값을 아래에 둡니다. 긴 소개는 두 칸을 다 씁니다.
편집
편집을 누르면 그 카드의 필드만 담은 패널이 열립니다. 저장하면 패널을 닫고 짧게 알립니다.
버리기
고친 내용이 있는데 패널을 닫으면 버릴지 먼저 묻습니다.
계정 삭제
계정 삭제는 메뉴 맨 아래 구분선 뒤에 빨간 글자로 둡니다. 누르면 위험 확인 대화상자가 열리고 계정 이메일을 입력해야 삭제됩니다.
