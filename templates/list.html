리스트

한 종류의 기록을 찾고 골라서 처리하는 화면입니다. 보안 이벤트 목록을 예로, 검색과 필터 줄, 선택 표와 액션 바, 페이지 이동을 둡니다.

언제 쓰는가
많은 행을 조건으로 좁히고, 여러 행을 골라 한꺼번에 처리할 때 씁니다.
비슷한 템플릿
같은 목록을 상태별로 나눠 보면 탭이 있는 리스트입니다.

Preview

실제 화면을 줄여 보여 줍니다. 안의 버튼과 메뉴도 동작합니다. 코드 보기를 누르면 화면 전체의 HTML 과 앱 틀 배치 CSS 를 볼 수 있습니다. 컴포넌트 모양은 사이트 스타일시트가 맡습니다.

Rules

툴바
검색칸이 남는 폭을 맞추고, 심각도와 기간을 같은 줄에 둡니다.
적용된 필터
결과 수와 적용된 필터 칩을 툴바 아래 한 줄에 두고, 필터 초기화를 함께 둡니다.
선택
액션 바는 표 위에 늘 있고, 고른 행이 없으면 버튼이 꺼집니다.
행 동작
행마다 더 보기 메뉴 하나에 동작을 모읍니다. 행 전체를 누르는 동작은 두지 않습니다.
정렬
기본은 최신 시간이 위입니다. 정렬한 머리글은 진한 글자와 화살표로 보입니다.
