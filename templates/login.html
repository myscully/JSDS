로그인

관리 콘솔에 들어오는 첫 화면입니다. 내비 없이 회색 바탕 가운데에 카드 하나를 두고, 로그인 뒤 2단계 인증 코드를 받습니다.

언제 쓰는가
이메일과 비밀번호로 콘솔에 들어오고, 이어서 인증 앱의 코드로 한 번 더 확인할 때 씁니다.
비슷한 템플릿
로그인 뒤 처음 보는 화면은 대시보드입니다.

Preview

실제 화면을 줄여 보여 줍니다. 안의 버튼과 메뉴도 동작합니다. 코드 보기를 누르면 화면 전체의 HTML 과 앱 틀 배치 CSS 를 볼 수 있습니다. 컴포넌트 모양은 사이트 스타일시트가 맡습니다.

Rules

화면
제품 로고와 카드, 아래 저작권 줄만 둡니다. 메뉴와 검색은 로그인한 뒤에 보입니다.
두 단계
비밀번호가 맞으면 같은 자리의 카드가 2단계 인증으로 바뀝니다. 주소는 그대로입니다.
포커스
코드 단계로 넘어가면 첫 번째 칸으로 포커스가 옮겨 바로 입력할 수 있습니다.
실패
로그인에 실패하면 카드 위에 이유와 다음 행동을 알립니다. 입력한 이메일은 지우지 않습니다.
