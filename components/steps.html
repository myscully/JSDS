Steps

온보딩 · 마법사처럼 순서대로 진행하는 일에서 지금 어디에 있는지 보여 줍니다. 같은 층위의 화면 전환은 Tab 을 씁니다.

단계 수
3~6단계입니다. 2단계면 표시하지 않고, 7단계를 넘으면 묶습니다. 빌드와 React 가 검사합니다.
라벨
1~2단어의 명사로 씁니다.
돌아가기
완료한 단계로만 돌아갈 수 있습니다. 앞 단계로 건너뛰지 않습니다.
상태
완료는 체크 아이콘과 숨긴 '(완료)' 문구, 현재는 aria-current="step" 로 알립니다.

1. Default

완료 .done, 현재 .on. 단계 사이는 선으로 잇습니다.

  1. 기본 정보 (완료)
  2. 적용 대상 (완료)
  3. 3규칙 설정
  4. 4검토 · 배포

Props

HTML 에서는 클래스와 속성으로, React(@jiran/ds-react)에서는 같은 이름의 prop(variant · size …)으로 변형·상태를 지정합니다.

Prop / ClassType · ValuesDefaultDescription
.steps
ol—진행 단계. aria-label 필수
.steps li
li—.done 완료(체크 아이콘 --foreground-positive-primary), .on 현재
.vertical
boolean
false
세로 배치
.step-btn
button—완료 단계로 돌아가는 버튼. .done 안에만
ds:step
event—돌아가기를 누르면 {index}. React onStepClick(index)

Usage

React: @jiran/ds-react 패키지를 설치하고 style.css 를 한 번 import 하면 위 React 탭 코드를 그대로 쓸 수 있습니다(React Package). HTML: assets/style.css 를 연결하고(일부만 필요하면 아래 컴포넌트 CSS 복사), 동작이 필요하면 assets/ds.js 를 함께 넣습니다 — 이 페이지의 프리뷰가 그 스크립트로 동작합니다. 색은 전부 토큰(var(--surface-brand-primary) 등)을 참조하므로 --accent-* 만 제품 컬러로 바꾸면 됩니다.

React @jiran/ds-react

npm i @jiran/ds-react

// main.tsx — 앱 진입점에서 한 번
import "@jiran/ds-react/style.css";

// 컴포넌트
import { Steps } from "@jiran/ds-react";

HTML

<!-- 1) 토큰 + 전체 컴포넌트 스타일 한 번에 연결 -->
<link rel="stylesheet" href="assets/style.css">
<!-- 동작(드롭다운·탭·달력·표 정렬/선택·토스트 등) — 순수 JS 한 파일. React 제품은 불필요 -->
<script src="assets/ds.js" defer></script>

<!-- 2) 또는 아래 "Component CSS" 만 프로젝트 CSS 에 붙이고,
        :root 토큰은 Foundations › Design Token 에서 복사 -->

복사본의 전제

아래 "Component CSS" 만 붙일 때는 이 규칙들과 Pretendard(assets/fonts) · :root 토큰을 전제로 그려집니다 — assets/style.css 의 값 그대로입니다. 앱에 같은 규칙이 있으면 넣지 않아도 됩니다.

*{box-sizing:border-box}
body{margin:0;background:var(--background-neutral-primary);color:var(--foreground-neutral-primary);font-family:var(--font-sans);font-size:16px;line-height:1.6;-webkit-font-smoothing:antialiased}
code,kbd{font-family:var(--font-sans);font-variant-numeric:tabular-nums}
