SelectN

옵션 목록을 열어 하나를 고릅니다. 옵션이 5개 이하이고 항상 보여야 하면 Radio · Select Button, 찾아야 하거나 여러 개를 고르면 Combobox, 고르는 것이 아니라 실행이면 Dropdown 을 씁니다.

언제 쓰는가
6개 이상의 보기에서 하나를 고를 때 씁니다. 5개 이하이고 늘 보여야 하면 Radio Button 이나 Select Button 을, 찾아서 고르거나 여러 개를 고르면 Combobox 를 씁니다.
Placement
필터 툴바, 폼 안의 선택 필드 · 아래 공간이 모자라면 위로 뒤집어 연다

Default

닫힌 기본 상태입니다. 고른 값이 없으면 트리거에 placeholder 를 둡니다. 항목이 8개를 넘으면 열린 목록은 최대 높이 320px 안에서 스크롤됩니다.

그룹 라벨로 묶습니다. 모든 옵션이 그룹에 들어갈 때만 쓰고, 그룹이 하나뿐이면 쓰지 않습니다
항목 글
한 줄로 씁니다. 짧게 구별되도록 앞에 다른 낱말을 둡니다
'전체' · '선택 안 함'
필터에는 맨 위에 '전체'를, 필수가 아닌 폼 항목에는 맨 위에 '선택 안 함'을 둡니다. '선택 안 함'을 고르면 값이 비워집니다. 필수 항목에는 두지 않습니다
목록 상태
불러오는 중 · 실패 · 항목 없음을 메뉴 안 한 줄로 보여 줍니다. 실패하면 다시 시도 버튼을 함께 둡니다
키보드
닫힌 트리거에서 ↑↓ 로 엽니다. 열리면 ↑↓ Home End 로 옮기고, 글자를 치면 그 글자로 시작하는 항목으로 갑니다. 초성으로도 찾습니다. Tab 은 닫고 다음 칸으로 갑니다
폼 안에서
필드로 감싸면 필드 폭을 채우고, 필드 라벨이 Select 의 이름으로 읽힙니다. 필수로 두면 Text Field 와 같은 검증에 참여합니다

Usage

React 제품은 디자인 시스템 패키지를 설치하고 스타일 파일을 한 번 불러오면 위 React 탭 코드를 그대로 쓸 수 있습니다. 설치 방법은 React Package 에 있습니다. HTML 제품은 공통 스타일 파일을 연결하고, 일부만 필요하면 아래 컴포넌트 CSS 를 복사합니다. 동작이 필요하면 동작 스크립트를 함께 넣습니다. 이 페이지의 미리보기도 그 스크립트로 움직입니다. 색은 모두 토큰을 따르므로 제품 색 하나를 고르면 나머지가 따라옵니다.

React @jiran/ds-react

npm i @jiran/ds-react

// main.tsx — 앱 진입점에서 한 번
import "@jiran/ds-react/style.css";

// 컴포넌트
import { Select } from "@jiran/ds-react";
