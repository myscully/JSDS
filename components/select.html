SelectN

옵션 목록을 열어 하나를 고릅니다. 옵션이 5개 이하이고 항상 보여야 하면 Radio · Select Button, 고르는 것이 아니라 실행이면 Dropdown 을 씁니다.

1. Default

닫힌 기본 상태입니다. 고른 값이 없으면 트리거에 placeholder 를 둡니다.

  • 전체
  • 영업팀
  • 개발팀
HTML
<div class="dropdown">
  <button type="button" class="trigger" aria-haspopup="listbox" aria-expanded="false"><span class="placeholder">그룹 선택</span></button>
  <ul class="menu" role="listbox" aria-label="그룹">
    <li class="menu-item" role="option">전체</li>
    <li class="menu-item" role="option">영업팀</li>
    <li class="menu-item" role="option">개발팀</li>
  </ul>
</div>

2. Open / Selected

  • 영업팀
  • 개발팀
  • 인프라팀

  • 영업팀

React · @jiran/ds-react
import { useState } from "react";
import { Select } from "@jiran/ds-react";

const GROUPS = [
  { value: "all", label: "전체" },
  { value: "sales", label: "영업팀" },
  { value: "dev", label: "개발팀" },
  { value: "infra", label: "인프라팀" },
  { value: "ext", label: "외주(권한 없음)", disabled: true },
];

export default function Example() {
  const [group, setGroup] = useState<string | null>("sales");
  return (
    <>
      <Select options={GROUPS} placeholder="그룹 선택" label="그룹" keepMounted />
      <Select options={GROUPS} value={group} onChange={setGroup} label="그룹" defaultOpen />
    </>
  );
}

Props

HTML 에서는 클래스와 속성으로, React(@jiran/ds-react)에서는 같은 이름의 prop(variant · size …)으로 변형·상태를 지정합니다.

Prop / ClassType · ValuesDefaultDescription
.dropdowncontainer—position:relative. 열림은 .open
.triggerbutton—고른 값을 표시. 값이 없으면 안에 .placeholder
.menuul—role=listbox · aria-label 필수
.menu-itemli—role=option. 고른 항목 .on + aria-selected, 비활성 aria-disabled

Usage

React: @jiran/ds-react 패키지를 설치하고 style.css 를 한 번 import 하면 위 React 탭 코드를 그대로 쓸 수 있습니다(React Package). HTML: assets/style.css 를 연결하고(일부만 필요하면 아래 컴포넌트 CSS 복사), 동작이 필요하면 assets/ds.js 를 함께 넣습니다 — 이 페이지의 프리뷰가 그 스크립트로 동작합니다. 색은 전부 토큰(var(--accent) 등)을 참조하므로 --accent-* 만 제품 컬러로 바꾸면 됩니다.

React @jiran/ds-react

npm i @jiran/ds-react

// main.tsx — 앱 진입점에서 한 번
import "@jiran/ds-react/style.css";

// 컴포넌트
import { Select } from "@jiran/ds-react";

HTML

<!-- 1) 토큰 + 전체 컴포넌트 스타일 한 번에 연결 -->
<link rel="stylesheet" href="assets/style.css">
<!-- 동작(드롭다운·탭·달력·표 정렬/선택·토스트 등) — 순수 JS 한 파일. React 제품은 불필요 -->
<script src="assets/ds.js" defer></script>

<!-- 2) 또는 아래 "Component CSS" 만 프로젝트 CSS 에 붙이고,
        :root 토큰은 Foundations › Design Token 에서 복사 -->
