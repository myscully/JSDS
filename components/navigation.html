v0.9 · 지란지교시큐리티 기획팀 디자인파트

Navigation

콘솔 좌측의 1차 내비게이션입니다. 그룹 라벨로 메뉴를 묶고 현재 위치를 강조합니다. 폭은 240px 이고, 접으면 64px 입니다.

언제 쓰는가
메뉴가 여러 그룹으로 나뉜 콘솔에서 1차 이동을 맡습니다. 상단 1차 메뉴와 함께 두지 않습니다.
Placement
헤더 아래 좌측 고정, 전체 높이

Default

그룹 라벨 아래에 링크를 둡니다. 아이콘은 18px 이고, 건수와 하위 항목을 함께 둘 수 있습니다.

Rules

깊이
2단계까지입니다.
이름
메뉴 이름과 페이지 제목, Breadcrumb 이름을 같게 씁니다.
권한
권한 없는 메뉴는 숨깁니다. 비활성으로 두지 않습니다.
접힘
아이콘만 남고 이름은 Tooltip 으로 보입니다. 마우스와 키보드 모두 볼 수 있습니다. 접은 상태는 사용자별로 기억합니다. 제품이 구현합니다.
본문 바로가기
페이지의 첫 포커스에 둡니다. 포커스가 오면 나타납니다.

Usage

React 제품은 디자인 시스템 패키지를 설치하고 스타일 파일을 한 번 불러오면 위 React 탭 코드를 그대로 쓸 수 있습니다. 설치 방법은 React Package 에 있습니다. HTML 제품은 공통 스타일 파일을 연결하고, 일부만 필요하면 아래 컴포넌트 CSS 를 복사합니다. 동작이 필요하면 동작 스크립트를 함께 넣습니다. 이 페이지의 미리보기도 그 스크립트로 움직입니다. 색은 모두 토큰을 따르므로 제품 색 하나를 고르면 나머지가 따라옵니다.

<!-- 동작(드롭다운·탭·달력·표 정렬/선택·토스트 등) — 순수 JS 한 파일. React 제품은 불필요 -->
