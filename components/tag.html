v0.8 · 지란지교시큐리티 기획팀 디자인파트

Tag

상태·분류·심각도를 짧게 표시합니다. 색만이 아니라 라벨 텍스트로도 의미를 전달합니다. 선택·삭제가 필요하면 Chip 을 씁니다.

톤
의미 색은 정해진 심각도 · 상태 어휘에만 씁니다. 사용자가 만든 라벨은 중립 또는 accent 입니다.
라벨
1~2단어로 씁니다. 사용자가 짓는 라벨은 입력에서 글자 수를 제한합니다. 폭 160 을 넘으면 줄바꿈합니다. 포커스를 받지 않아 잘라 내면 읽을 길이 없습니다.
누를 수 없음
Tag 는 표시 전용입니다. 선택 · 삭제는 Chip 을 씁니다.
여러 개
표 칸은 앞 2개와 +N 을 보이고 나머지는 Tooltip 으로 보여 줍니다. +N 은 포커스를 받는 버튼입니다. 표 밖에서는 줄바꿈해 전부 보입니다.

의미 색을 지정하지 않은 중립 태그입니다.
