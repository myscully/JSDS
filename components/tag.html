Tag

상태 · 분류 · 심각도를 짧게 표시합니다. 색만이 아니라 라벨 글자로도 뜻을 전합니다.

언제 쓰는가
상태나 분류, 심각도를 읽기만 하도록 보여 줄 때 씁니다. 사용자가 누르거나 지울 수 있어야 하면 Chip 을, 건수를 보여 줄 때는 Indicator 를 씁니다.
Placement
테이블 셀, 카드 헤더, 상세 패널 제목 옆

Default

의미 색을 지정하지 않은 중립 태그입니다.

Rules

톤
의미 색은 정해진 심각도 · 상태 어휘에만 씁니다. 사용자가 만든 라벨은 중립이나 강조색으로 씁니다.
색
색은 옅은 틴트 면과 같은 색상의 진한 글자가 나릅니다. 점은 기본으로 없고 필요할 때만 켭니다. 라벨 글자가 늘 등급 이름이라 색만으로 뜻을 전하지 않습니다.
라벨
1~2단어로 씁니다. 사용자가 짓는 라벨은 입력할 때 글자 수를 제한합니다. 폭 160px 을 넘으면 자르지 않고 줄바꿈합니다. Tag 는 포커스를 받지 않으므로 잘라 내면 읽을 길이 없습니다.
누를 수 없음
Tag 는 표시 전용입니다. 선택 · 삭제는 Chip 을 씁니다.
여러 개
표 칸에서는 앞 2개와 남은 개수 '+N' 을 보이고, 나머지는 Tooltip 으로 보여 줍니다. '+N' 은 포커스를 받는 버튼입니다. 표 밖에서는 줄바꿈해 전부 보입니다.
