Tag

상태·분류·심각도를 짧게 표시합니다. 색만이 아니라 라벨 텍스트로도 의미를 전달합니다. 선택·삭제가 필요하면 Chip 을 씁니다.

  2. 2Label

Examples

1. Severity

위협 심각도 5단계. --sev-* 토큰과 1:1.

Critical High Medium Low Info
HTML
<span class="tag critical">Critical</span>
<span class="tag high">High</span>
<span class="tag medium">Medium</span>
<span class="tag low">Low</span>
<span class="tag info">Info</span>
CSS · .tag
/* JS Design System v0.6 · .tag · 토큰(var(--*))은 assets/style.css :root 참고 */

.tag.medium{background:var(--warning-subtle);color:var(--sev-medium)}
.tag.low{background:var(--info-subtle);color:var(--sev-low)}
.tag.info{background:var(--bg-panel);color:var(--sev-info)}

Props

HTML 에서는 클래스와 속성으로, React(@jiran/ds-react)에서는 같은 이름의 prop(variant · size …)으로 변형·상태를 지정합니다.

Prop / ClassType · ValuesDefaultDescription
tonecritical | high | medium | low | info | ok | accent | (neutral)neutral의미별 색. severity 는 --sev-*, status 는 feedback 토큰
style.outline | .solid | .plainsubtle아웃라인 / 채움 / 점 없음
sizesm | (md) | lgmd폰트 11 / 12 / 13

Usage

React: @jiran/ds-react 패키지를 설치하고 style.css 를 한 번 import 하면 위 React 탭 코드를 그대로 쓸 수 있습니다(React Package). HTML: assets/style.css 를 연결하고(일부만 필요하면 아래 컴포넌트 CSS 복사), 동작이 필요하면 assets/ds.js 를 함께 넣습니다 — 이 페이지의 프리뷰가 그 스크립트로 동작합니다. 색은 전부 토큰(var(--accent) 등)을 참조하므로 --accent-* 만 제품 컬러로 바꾸면 됩니다.

React @jiran/ds-react

npm i @jiran/ds-react

// main.tsx — 앱 진입점에서 한 번
import "@jiran/ds-react/style.css";

// 컴포넌트
import { Tag } from "@jiran/ds-react";

HTML

<!-- 1) 토큰 + 전체 컴포넌트 스타일 한 번에 연결 -->
<link rel="stylesheet" href="assets/style.css">
<!-- 동작(드롭다운·탭·달력·표 정렬/선택·토스트 등) — 순수 JS 한 파일. React 제품은 불필요 -->
<script src="assets/ds.js" defer></script>

<!-- 2) 또는 아래 "Component CSS" 만 프로젝트 CSS 에 붙이고,
        :root 토큰은 Foundations › Design Token 에서 복사 -->
