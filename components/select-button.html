v0.8 · 지란지교시큐리티 기획팀 디자인파트

Select Button

2~5개 옵션 중 하나를 고르는 세그먼트 컨트롤입니다. 뷰 전환(목록/카드), 기간(24시간/7일/30일)처럼 즉시 반영되는 선택에 씁니다.

언제 쓰는가
2~5개 중 하나를 고르고, 같은 내용에서 보기나 기간만 바뀔 때 씁니다. 내용이 달라지면 Tab 을, 저장해야 반영되면 Radio Button 을, 6개 이상이면 Select 를 씁니다.
Placement
카드 헤더 우측, 툴바

Default

선택된 항목에 .on. 컨테이너에 role=radiogroup, 버튼에 role=radio · aria-checked. Tab 은 한 번만 멈추고 화살표로 옮깁니다.

HTML
<div class="select-btn" role="radiogroup" aria-label="기간">
  <button type="button" class="on" role="radio" aria-checked="true">24시간</button>
  <button type="button" role="radio" aria-checked="false">7일</button>
  <button type="button" role="radio" aria-checked="false">30일</button>
</div>

Rules

항상 하나
언제나 하나가 선택되어 있습니다. 선택을 푸는 동작은 없습니다
라벨
1~2단어로 쓰고 항목끼리 길이를 비슷하게 맞춥니다
키보드
Tab 은 묶음에 한 번만 멈춥니다. 좌우 · 상하 화살표로 옮기면 바로 고르고, 비활성은 건너뛰며 끝에서 처음으로 돌아옵니다

Usage

React: @jiran/ds-react 패키지를 설치하고 style.css 를 한 번 import 하면 위 React 탭 코드를 그대로 쓸 수 있습니다(React Package). HTML: assets/style.css 를 연결하고(일부만 필요하면 아래 컴포넌트 CSS 복사), 동작이 필요하면 assets/ds.js 를 함께 넣습니다 — 이 페이지의 프리뷰가 그 스크립트로 동작합니다. 색은 전부 토큰(var(--surface-brand-primary) 등)을 참조하므로 --accent-* 만 제품 컬러로 바꾸면 됩니다.

React @jiran/ds-react

npm i @jiran/ds-react

// main.tsx — 앱 진입점에서 한 번
import "@jiran/ds-react/style.css";

// 컴포넌트
import { SelectButton } from "@jiran/ds-react";

HTML

<!-- 1) 토큰 + 전체 컴포넌트 스타일 한 번에 연결 -->
<link rel="stylesheet" href="assets/style.css">
<!-- 동작(드롭다운·탭·달력·표 정렬/선택·토스트 등) — 순수 JS 한 파일. React 제품은 불필요 -->
<script src="assets/ds.js" defer></script>

<!-- 2) 또는 아래 "Component CSS" 만 프로젝트 CSS 에 붙이고,
        :root 토큰은 Foundations › Design Token 에서 복사 -->

복사본의 전제

아래 "Component CSS" 만 붙일 때는 이 규칙들과 Pretendard(assets/fonts) · :root 토큰을 전제로 그려집니다 — assets/style.css 의 값 그대로입니다. 앱에 같은 규칙이 있으면 넣지 않아도 됩니다.

*{box-sizing:border-box}
body{margin:0;background:var(--background-neutral-primary);color:var(--foreground-neutral-primary);font-family:var(--font-sans);font-size:var(--font-size-16);line-height:1.6;-webkit-font-smoothing:antialiased}
code,kbd{font-family:var(--font-sans);font-variant-numeric:tabular-nums}
