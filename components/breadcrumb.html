Breadcrumb

지금 화면이 메뉴 계층의 어디인지 보여 주고 상위로 한 번에 돌아가게 합니다. 좌측 메뉴에 바로 있는 화면은 메뉴가 이미 위치를 보여 주므로 두지 않고, 그 아래로 들어간 상세 · 편집 · 하위 화면에만 둡니다.

1. Default

홈 아이콘 › 메뉴 › … › 현재 페이지. 첫 항목은 항상 홈 아이콘이고 aria-label="홈" 이 필수입니다. 마지막은 현재 페이지로, 링크 없이 Medium 이며 페이지 타이틀과 같은 이름입니다.

  2. 정책
  3. USB 제어
  4. 외부 저장장치 차단

2. State

Normal · Hover · Focus · Current 네 가지입니다. Hover 는 글자를 primary 로 바꾸고 밑줄을 긋습니다(가운데 항목은 Hover 를 고정해 보입니다). Focus 는 전역 포커스 외곽선입니다 — Tab 으로 확인하세요. Disabled 는 두지 않습니다.

  2. Normal
  3. Hover
  4. Current

3. Long label

메뉴 항목은 메뉴에 적힌 이름 그대로, 상세 화면은 대상 이름(정책 · 장비 이름)을 씁니다. 220px 를 넘으면 말줄임하고, 잘린 항목에만 Tooltip 이 붙어 마우스와 키보드로 전체 문구를 봅니다. 링크가 아닌 현재 항목도 잘렸을 때는 포커스를 받습니다.

4. Non-link parent
