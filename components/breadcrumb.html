Breadcrumb

지금 화면이 메뉴 계층의 어디인지 보여 주고 상위로 한 번에 돌아가게 합니다. 좌측 메뉴에 바로 있는 화면은 메뉴가 이미 위치를 보여 주므로 두지 않고, 그 아래로 들어간 상세 · 편집 · 하위 화면에만 둡니다.

1. Default

홈 아이콘 › 메뉴 › … › 현재 페이지. 첫 항목은 항상 홈 아이콘이고 aria-label="홈" 이 필수입니다. 마지막은 현재 페이지로, 링크 없이 SemiBold 이며 페이지 타이틀과 같은 이름입니다.

  2. 정책
  3. USB 제어
  4. 외부 저장장치 차단

2. State

Normal · Hover · Focus · Current 네 가지입니다. Hover 는 글자를 primary 로 바꾸고 밑줄을 긋습니다(가운데 항목은 Hover 를 고정해 보입니다). Focus 는 전역 포커스 외곽선입니다 — Tab 으로 확인하세요. Disabled 는 두지 않습니다.

  3. Hover
  4. Current

  }, [open]);
  return (

      <BreadcrumbHome href="#" />

        : <BreadcrumbMore onClick={() => setOpen(true)} />}
      <BreadcrumbItem href="#">PC-2041</BreadcrumbItem>
