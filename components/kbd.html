KbdN, 새 항목

키보드 단축키를 키 모양으로 보입니다. 단축키가 실제로 동작하는 자리에만 둡니다.

언제 쓰는가
검색창 · 메뉴 항목 · 버튼에 단축키가 있을 때 그 키를 보입니다. 명령어나 설정 값처럼 그대로 옮겨 적는 글은 Code 로 씁니다.
비슷한 것
상태나 분류를 붙이는 표시는 Tag 입니다.
Placement
검색창 오른쪽 끝 · 메뉴 항목 오른쪽 끝 · Tooltip 라벨 뒤 · 단축키 도움말 표

export default function Example() {
  const [open, setOpen] = useState(false);

    const h = (e: KeyboardEvent) => {

Rules

동작하는 키만
보이는 키는 그 화면에서 실제로 동작해야 합니다. 동작하지 않는 키를 보이면 사용자가 눌러 보고 실패합니다.
운영체제
수정 키는 맥에서 Command 기호로, 그 밖에서는 Ctrl 로 보입니다. 기호는 화면 낭독기가 읽지 못해 이름을 숨겨 둡니다.
조합
함께 누르는 키는 키 모양을 나란히 둡니다. 키 사이에 더하기 기호를 넣지 않습니다.
입력 중
글자 하나로 된 단축키는 입력칸에 글을 치는 동안 동작하지 않습니다. 수정 키를 함께 누르는 단축키만 입력 중에도 동작합니다.
단축키 도움말
단축키가 셋 이상인 화면은 물음표 키로 여는 도움말을 둡니다. 도움말은 그 화면의 단축키만 보입니다.
글자
키 이름은 키보드에 적힌 대로 씁니다. 한 글자 키는 대문자로 씁니다.
