React · @jiran/ds-react
import { useState } from "react";
import { Select } from "@jiran/ds-react";

const GROUPS = [
  { value: "all", label: "전체" },
  { value: "sales", label: "영업팀" },
  { value: "dev", label: "개발팀" },
  { value: "infra", label: "인프라팀" },
  { value: "ext", label: "외주(권한 없음)", disabled: true },
];

export default function Example() {
  const [group, setGroup] = useState<string | null>("sales");
  return (
    <>
      <Select options={GROUPS} placeholder="그룹 선택" label="그룹" />
      <Select options={GROUPS} value={group} onChange={setGroup} label="그룹" defaultOpen />
    </>
  );
}

Props

HTML 에서는 클래스와 속성으로, React(@jiran/ds-react)에서는 같은 이름의 prop(variant · size …)으로 변형·상태를 지정합니다.

Prop / ClassType · ValuesDefaultDescription
.dropdowncontainer—position:relative. 열림은 .open
.triggerbutton—현재 값 표시. 값 없으면 .placeholder
.menuul—role=listbox(선택) 또는 menu(액션)
.menu-itemli—.on 선택, .danger 위험, aria-disabled 비활성, .hint 단축키
.menu-sep / .menu-labelli—구분선 / 그룹 라벨

Usage

React: @jiran/ds-react 패키지를 설치하고 style.css 를 한 번 import 하면 위 React 탭 코드를 그대로 쓸 수 있습니다(React Package). HTML: assets/style.css 를 연결하고(일부만 필요하면 아래 컴포넌트 CSS 복사), 동작이 필요하면 assets/ds.js 를 함께 넣습니다 — 이 페이지의 프리뷰가 그 스크립트로 동작합니다. 색은 전부 토큰(var(--accent) 등)을 참조하므로 --accent-* 만 제품 컬러로 바꾸면 됩니다.
