2. Variant · Color

형태는 Solid 와 Outline 두 가지, 색은 Primary(기본) · Assistive · Negative 세 가지입니다. Negative 는 위험 · 경고성 행동에만 씁니다. 제품 메인 컬러가 상태색과 겹치면 제품 컬러가 쓰이는 곳이 모두 중립색으로 내려가, Primary 도 함께 바뀝니다.

3. Priority

Lv.4 Primary Solid — 화면에서 가장 중요한 메인 행동을 유도 · 제안합니다. Lv.3 Primary Outline — 미리보기 · 임시 저장처럼 대체 행동을 제안합니다. Lv.2 Assistive Solid — 토글 버튼을 보조합니다. Lv.1 Assistive Outline — 닫기 · 취소 같은 보조 행동을 제시합니다. 삭제 · 탈퇴처럼 되돌리기 어려운 행동에는 우선순위와 별개로 Negative 를 씁니다.

Usage

React: @jiran/ds-react 패키지를 설치하고 style.css 를 한 번 import 하면 위 React 탭 코드를 그대로 쓸 수 있습니다(React Package). HTML: assets/style.css 를 연결하고(일부만 필요하면 아래 컴포넌트 CSS 복사), 동작이 필요하면 assets/ds.js 를 함께 넣습니다 — 이 페이지의 프리뷰가 그 스크립트로 동작합니다. 색은 전부 토큰(var(--surface-brand-primary) 등)을 참조하므로 --accent-* 만 제품 컬러로 바꾸면 됩니다.

React @jiran/ds-react

npm i @jiran/ds-react

// main.tsx — 앱 진입점에서 한 번
import "@jiran/ds-react/style.css";

// 컴포넌트
import { Button, ButtonGroup } from "@jiran/ds-react";

HTML

<!-- 1) 토큰 + 전체 컴포넌트 스타일 한 번에 연결 -->
<link rel="stylesheet" href="assets/style.css">
<!-- 동작(드롭다운·탭·달력·표 정렬/선택·토스트 등) — 순수 JS 한 파일. React 제품은 불필요 -->
<script src="assets/ds.js" defer></script>
