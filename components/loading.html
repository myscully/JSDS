Loading

기다리는 동안의 상태를 알립니다. 영역의 첫 로딩은 Skeleton, 짧은 동작은 Spinner, 진행률을 알면 Progress 를 씁니다.

언제 쓰는가
어떤 표시를 쓸지는 기다리는 시간으로 고르고, 그 기준은 Interaction 의 Loading 표를 따릅니다.
Placement
Skeleton 은 콘텐츠 자리 그대로, Spinner 는 영역 중앙

Default

기본 크기(24px) 스피너입니다.

Rules

1초 미만
금방 끝날 수도 있는 기다림에는 data-delay · React delay 를 답니다. 1초 안에 끝나면 표시가 깜빡이지 않습니다. 한 번 보이면 0.5초는 유지합니다(DS.loading · useLoadingDelay).
누른 반응
버튼 loading · Switch 처리 중은 기다리지 않습니다. 누른 반응이 바로 보여야 두 번 누르지 않습니다. 빌드가 검사합니다.
Spinner 이름
'불러오는 중' 만 쓰지 않고 실제 작업을 적습니다. 빌드가 검사합니다.
Skeleton
완성될 콘텐츠의 크기와 모양에 맞춥니다.
Progress
진행률을 알 때만 씁니다. value 는 필수이고, 끝을 알 수 없는 진행 막대는 제공하지 않습니다. 그때는 Spinner 를 씁니다.
오래 걸리는 작업
취소하거나 백그라운드로 돌릴 길을 제공합니다.
줄인 모션

Usage

React: @jiran/ds-react 패키지를 설치하고 style.css 를 한 번 import 하면 위 React 탭 코드를 그대로 쓸 수 있습니다(React Package). HTML: assets/style.css 를 연결하고(일부만 필요하면 아래 컴포넌트 CSS 복사), 동작이 필요하면 assets/ds.js 를 함께 넣습니다 — 이 페이지의 프리뷰가 그 스크립트로 동작합니다. 색은 전부 토큰(var(--surface-brand-primary) 등)을 참조하므로 --accent-* 만 제품 컬러로 바꾸면 됩니다.

React @jiran/ds-react

npm i @jiran/ds-react

// main.tsx — 앱 진입점에서 한 번
import "@jiran/ds-react/style.css";

// 컴포넌트
import { Spinner, Skeleton, SkeletonRow, Progress } from "@jiran/ds-react";

HTML

<!-- 1) 토큰 + 전체 컴포넌트 스타일 한 번에 연결 -->
<link rel="stylesheet" href="assets/style.css">
<!-- 동작(드롭다운·탭·달력·표 정렬/선택·토스트 등) — 순수 JS 한 파일. React 제품은 불필요 -->
<script src="assets/ds.js" defer></script>

<!-- 2) 또는 아래 "Component CSS" 만 프로젝트 CSS 에 붙이고,
        :root 토큰은 Foundations › Design Token 에서 복사 -->
