Time Picker

백업 시각이나 점검 시작 시각처럼 날짜 없이 하루 안의 시각을 입력합니다. 직접 치거나 시 · 분 열에서 고르면 바로 값이 됩니다.

언제 쓰는가
날짜와 상관없이 하루 안의 시각만 받을 때 씁니다. 매일 도는 백업 시각, 점검 시작 시각, 업무 시간대의 시작과 끝 같은 값입니다.
비슷한 것
날짜와 시각을 함께 받는 값은 Date Picker 의 시각 옵션을 씁니다. 그 달력 아래 시각 칸도 이 Time Picker 입니다. 몇 분이나 몇 초 같은 길이는 시각이 아니므로 Number Input 으로 받습니다.
Placement
폼의 값 자리 · 정책 일정 설정

Default

직접 치거나 시계 버튼으로 열 목록을 엽니다. 칸을 고르면 바로 값이 됩니다.

매일 이 시각에 백업합니다.

Rules

형식
24시간제 HH:mm 형식입니다. 초가 필요하면 HH:mm:ss 형식으로 받습니다. 오전 · 오후 표기는 쓰지 않습니다.
입력
숫자만 쳐도 콜론이 채워집니다. 위 · 아래 화살표는 커서가 놓인 조각을 하나씩 바꾸고, 23 다음은 00 으로 돕니다.
열 목록
시계 버튼이나 Alt + 아래 화살표로 엽니다. 칸을 고르면 바로 값이 되고 비어 있던 조각은 00 으로 채웁니다. 적용 버튼은 두지 않습니다.
팝업 안
팝업이나 패널 본문 안에서도 열 목록은 본문에 잘리지 않고 그 위로 뜹니다. 본문을 스크롤하면 필드를 따라가고, 필드가 보이지 않게 되면 닫힙니다.
폭
혼자 놓이면 최소 폭으로 둡니다. 폼 안에서는 다른 필드처럼 칸 폭을 채우고, 칸이 좁아도 최소 폭보다 줄지 않습니다.
간격
간격은 분 열에 보이는 칸 사이의 간격입니다. 직접 친 값은 간격과 맞지 않아도 받습니다.
범위
최소 · 최대 시각 밖의 칸은 고를 수 없습니다. 직접 친 범위 밖 값은 받고, 필드를 떠날 때 오류로 알립니다. 받을 수 있는 범위는 도움말에 미리 적습니다.
키보드
열 안에서는 위 · 아래 화살표와 Home · End 로 옮기고, 왼쪽 · 오른쪽 화살표로 열을 바꿉니다. Enter 는 고르고 다음 열로 가며, 마지막 열에서는 닫고 입력칸으로 돌아갑니다. Esc 는 닫습니다. Tab 은 열 사이를 옮기고, 필드를 떠나면 닫힙니다.
