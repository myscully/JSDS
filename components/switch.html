Switch

설정을 켜고 끕니다. 토글 즉시 적용되며 저장 버튼이 없습니다. 저장이 필요한 폼 안에서는 Checkbox 를 씁니다.

언제 쓰는가
누르면 바로 적용되는 켜기 · 끄기입니다. 저장 버튼이 있는 폼에서는 Checkbox 입니다
언제 바뀌는가
서버를 거치면 응답을 받은 뒤에 바뀝니다. 보안 설정이 실제와 다르게 보이는 순간을 만들지 않습니다
처리 중
노브에 스피너를 띄우고 다시 누를 수 없게 막습니다. 포커스는 그 자리에 남습니다
실패
상태를 바꾸지 않고 이유를 닫을 때까지 남는 Toast 로 알립니다
보안 기능을 끌 때
Interaction 의 위험 동작 표대로 Popup 으로 확인한 뒤 처리합니다. 취소하면 조용히 그대로 둡니다
라벨
켜짐 · 꺼짐에 따라 바꾸지 않습니다. 상태를 말하지 않고 켜지는 대상을 씁니다(실시간 보호)
비활성
왜 바꿀 수 없는지 설명 자리에 적습니다. 비활성 요소에는 Tooltip 을 달지 않습니다
표 안
'사용' 열의 Switch 는 행마다 다른 접근 이름을 줍니다(외부 USB 차단 사용)

3. 처리 중 · 실패

<label class="switch" data-async><input type="checkbox" role="switch" checked aria-busy="true" aria-disabled="true"><span>웹 필터</span></label>

React · @jiran/ds-react
import { Switch, ToastProvider } from "@jiran/ds-react";

const save = () => new Promise((resolve) => setTimeout(resolve, 900));
const fail = () => new Promise((_, reject) => setTimeout(reject, 900));

/** action 이 끝나야 바뀐다. false 를 돌려주면 그대로(확인 Popup 취소), 던지면 Toast 로 알린다 */
export default function Example() {
  return (
    <ToastProvider>
      <Switch defaultChecked action={save}>실시간 보호</Switch>
      <Switch action={fail} errorMessage="정책 서버에 연결하지 못했습니다. 잠시 후 다시 시도하세요.">USB 자동 검사</Switch>
      <Switch defaultChecked busy>웹 필터</Switch>
    </ToastProvider>
  );
}

attribute—처리 중(ds.js 가 넣는다). 노브 스피너, 조작 막음

Usage

React: @jiran/ds-react 패키지를 설치하고 style.css 를 한 번 import 하면 위 React 탭 코드를 그대로 쓸 수 있습니다(React Package). HTML: assets/style.css 를 연결하고(일부만 필요하면 아래 컴포넌트 CSS 복사), 동작이 필요하면 assets/ds.js 를 함께 넣습니다 — 이 페이지의 프리뷰가 그 스크립트로 동작합니다. 색은 전부 토큰(var(--surface-brand-primary) 등)을 참조하므로 --accent-* 만 제품 컬러로 바꾸면 됩니다.
