v0.8 · 지란지교시큐리티 기획팀 디자인파트

Search

목록·로그를 빠르게 필터링하는 검색 입력입니다. 입력이 멈추면 결과가 바뀌는 '필터형'과 Enter 로 조회하는 '조회형'을 구분합니다.

필터형 · 조회형
이미 불러온 목록을 좁히면 필터형입니다. data-debounce 로 입력이 멈추고 300ms 뒤에 결과를 바꿉니다. 서버에 새로 묻거나 비용이 크면 조회형으로 Enter 에 맡깁니다
Placeholder
검색 대상을 씁니다. 검색 아이콘과 접근 이름(aria-label)이 있을 때만 보이는 라벨 없이 쓸 수 있습니다
지우기
값이 있을 때만 보입니다. Esc 도 같은 동작입니다. 값이 없으면 검색창은 Esc 에 반응하지 않습니다
단축키
/ 는 화면에 하나뿐인 주 검색에만 답니다. 입력 중 · 조합키 · 모달이 열린 동안에는 무시합니다
결과 건수
결과가 바뀌면 숨긴 라이브 영역으로 건수를 알립니다. 보이는 건수는 목록 툴바에 둡니다
결과 없음
Empty State 의 검색 결과 없음으로 잇습니다. 조건을 보여 주고 초기화 · 완화를 제안합니다
조건 유지
검색어와 필터를 URL 에 남겨 공유 · 새로고침해도 유지합니다. 제품이 구현합니다

import { useState } from "react";
import { Chip, ChipGroup, SearchBar } from "@jiran/ds-react";

const FILTERS = ["Critical", "High", "Medium", "Low", "Info", "최근 24시간"];

export default function Example() {
  const [sel, setSel] = useState(["Critical", "High"]);
  return (
    <div style={{ display: "flex", flexDirection: "column", gap: 12, width: "100%", maxWidth: 720 }}>
      <SearchBar block debounce placeholder="로그 검색" label="로그 검색" status="128건" />
      <ChipGroup clearable={sel.length > 0} onClear={() => setSel([])}>
        {FILTERS.map((f) => (
          <Chip key={f} selected={sel.includes(f)} onSelectedChange={(on) => setSel((s) => (on ? [...s, f] : s.filter((x) => x !== f)))}>{f}</Chip>
        ))}
      </ChipGroup>
    </div>
  );
}

Usage

React: @jiran/ds-react 패키지를 설치하고 style.css 를 한 번 import 하면 위 React 탭 코드를 그대로 쓸 수 있습니다(React Package). HTML: assets/style.css 를 연결하고(일부만 필요하면 아래 컴포넌트 CSS 복사), 동작이 필요하면 assets/ds.js 를 함께 넣습니다 — 이 페이지의 프리뷰가 그 스크립트로 동작합니다. 색은 전부 토큰(var(--surface-brand-primary) 등)을 참조하므로 --accent-* 만 제품 컬러로 바꾸면 됩니다.
