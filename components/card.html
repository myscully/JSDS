Card

관련 정보와 그 정보에 대한 액션을 한 덩어리로 묶는 컨테이너입니다. 대시보드 위젯 · 상세 화면의 정보 블록 · 선택지 묶음에 씁니다.

언제 쓰는가
관련된 정보와 그 정보로 할 수 있는 동작을 한 덩어리로 묶을 때 씁니다. 숫자 하나를 강조하려면 KPI 를, 그래프를 담으려면 Chart Card 를 씁니다. 화면 전체를 감싸는 틀로는 쓰지 않습니다.
Placement
대시보드 그리드(minmax 260 · gap 20) · 상세 정보 블록 · 선택지 묶음 · 카드 안 카드 금지

Default

헤더 · 본문 · 푸터 순서로 둡니다. 헤더에는 제목과 오른쪽 요소 하나를 둡니다. 푸터 동작은 오른쪽에 모으고 강조 버튼은 하나만 둡니다. 카드 면과 1px 테두리로 구획하고 그림자는 두지 않습니다.

Usage

React 제품은 디자인 시스템 패키지를 설치하고 스타일 파일을 한 번 불러오면 위 React 탭 코드를 그대로 쓸 수 있습니다. 설치 방법은 React Package 에 있습니다. HTML 제품은 공통 스타일 파일을 연결하고, 일부만 필요하면 아래 컴포넌트 CSS 를 복사합니다. 동작이 필요하면 동작 스크립트를 함께 넣습니다. 이 페이지의 미리보기도 그 스크립트로 움직입니다. 색은 모두 토큰을 따르므로 제품 색 하나를 고르면 나머지가 따라옵니다.
