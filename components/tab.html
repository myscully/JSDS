v0.8 · 지란지교시큐리티 기획팀 디자인파트

Tab

같은 맥락의 콘텐츠를 뷰 단위로 전환합니다. 페이지 수준은 Underline, 카드 안의 보조 전환은 Pill.

언제
같은 대상의 보기를 바꿀 때 씁니다. 페이지를 옮기는 메뉴에 쓰지 않고, 표의 필터는 Filter Chip 을 씁니다. 동시에 봐야 할 정보는 나누지 않습니다.
순서 · 제목
중요도와 빈도 순으로 둡니다. 모든 탭에 공통인 제목은 탭 위에 둡니다.
라벨
1~2단어로 씁니다. 빌드가 검사합니다.
넘칠 때
탭 줄만 옆으로 스크롤합니다. 고른 탭은 자동으로 보이는 자리에 옵니다. 탭을 메뉴로 접어 숨기지 않습니다.
키보드
←→ · Home · End 로 옮기면 바로 전환합니다. Tab 키는 다음 탭이 아니라 패널로 갑니다.
패널의 입력
탭을 옮겨도 패널을 숨기기만 하고 입력은 남겨 둡니다. 패널을 지워야 하는 제품은 확인 Popup 을 띄웁니다.
URL
활성 탭을 URL 에 남겨 공유와 새로고침에 유지합니다. 제품이 구현합니다.
