Tab

같은 맥락의 콘텐츠를 뷰 단위로 전환합니다. 페이지 수준은 Underline, 카드 안의 보조 전환은 Pill.

완료Figma ↗DesktopHTML+CSS · React

Examples

1. Underline

기본. role=tablist / tab / aria-selected. 활성은 .on.

선택한 탭의 내용이 여기에 표시됩니다.
HTML
<div style="width:100%;max-width:640px">
  <div class="tabs" role="tablist">
    <button type="button" class="tab on" role="tab" aria-selected="true">개요</button>
    <button type="button" class="tab" role="tab" aria-selected="false">이벤트</button>
    <button type="button" class="tab" role="tab" aria-selected="false">정책</button>
    <button type="button" class="tab" role="tab" aria-selected="false" disabled>리포트</button>
  </div>
  <div class="tab-panel" role="tabpanel">선택한 탭의 내용이 여기에 표시됩니다.</div>
</div>
CSS · .tabs, .tab-panel
/* JS Design System v0.6 · .tabs, .tab-panel · 토큰(var(--*))은 assets/style.css :root 참고 */
.tabs{display:flex;gap:24px;border-bottom:1px solid var(--border-default);width:100%}
.tabs .tab{display:inline-flex;align-items:center;gap:6px;padding:10px 2px;border:0;border-bottom:2px solid transparent;margin-bottom:-1px;background:transparent;font:inherit;font-size:14px;font-weight:500;color:var(--text-tertiary);cursor:pointer;white-space:nowrap;transition:color var(--motion-fast)}
.tabs .tab:hover{color:var(--text-primary)}
.tabs .tab.on{color:var(--text-primary);font-weight:700;border-bottom-color:var(--text-primary)}
.tabs .tab[disabled]{opacity:.4;cursor:not-allowed}
.tabs .tab .count{font-size:12px;font-weight:700;padding:1px 6px;border-radius:999px;background:var(--bg-panel);color:var(--text-secondary);min-width:0;height:auto}
.tabs .tab.on .count{background:var(--accent-subtle);color:var(--accent)}
.tabs.accent .tab.on{color:var(--accent);border-bottom-color:var(--accent)}
.tabs.pill{display:inline-flex;gap:4px;border:0;background:var(--bg-panel);padding:3px;border-radius:var(--radius-md);width:auto}
.tabs.pill .tab{padding:6px 14px;border:0;border-radius:6px;margin:0;font-size:14px}
.tabs.pill .tab.on{background:var(--bg-surface);box-shadow:var(--shadow-1);font-weight:600}
.tabs.sm .tab{font-size:12px;padding:8px 2px}
.tab-panel{padding:20px 0;font-size:14px;color:var(--text-secondary)}
React · @jiran/ds-react
import { Tab, TabList, TabPanel, Tabs } from "@jiran/ds-react";

export default function Example() {
  return (
    <div style={{ width: "100%", maxWidth: 640 }}>
      <Tabs defaultValue="overview">
        <TabList>
          <Tab value="overview">개요</Tab>
          <Tab value="events">이벤트</Tab>
          <Tab value="policy">정책</Tab>
          <Tab value="report" disabled>리포트</Tab>
        </TabList>
        <TabPanel value="overview">선택한 탭의 내용이 여기에 표시됩니다.</TabPanel>
        <TabPanel value="events">이벤트 목록</TabPanel>
        <TabPanel value="policy">정책 목록</TabPanel>
      </Tabs>
    </div>
  );
}

Props

HTML 에서는 클래스와 속성으로, React(@jiran/ds-react)에서는 같은 이름의 prop(variant · size …)으로 변형·상태를 지정합니다.

Prop / ClassType · ValuesDefaultDescription
.tabscontainer—role=tablist. 기본 Underline, 전체 폭
.tabbutton—role=tab, aria-selected. 활성 .on
.pillbooleanfalse캡슐형(보조 전환)
.sm / .accentbooleanfalse작은 크기 / 활성 색 accent
.countelement—건수 배지
disabledattribute—비활성 탭

Usage

React: @jiran/ds-react 패키지를 설치하고 style.css 를 한 번 import 하면 위 React 탭 코드를 그대로 쓸 수 있습니다(React Package). HTML: assets/style.css 를 연결하고(일부만 필요하면 아래 컴포넌트 CSS 복사), 동작이 필요하면 assets/ds.js 를 함께 넣습니다 — 이 페이지의 프리뷰가 그 스크립트로 동작합니다. 색은 전부 토큰(var(--accent) 등)을 참조하므로 --accent-* 만 제품 컬러로 바꾸면 됩니다.

React @jiran/ds-react

npm i @jiran/ds-react

// main.tsx — 앱 진입점에서 한 번
import "@jiran/ds-react/style.css";

// 컴포넌트
import { Tabs, TabList, Tab, TabPanel } from "@jiran/ds-react";

HTML

<!-- 1) 토큰 + 전체 컴포넌트 스타일 한 번에 연결 -->
<link rel="stylesheet" href="assets/style.css">
<!-- 동작(드롭다운·탭·달력·표 정렬/선택·토스트 등) — 순수 JS 한 파일. React 제품은 불필요 -->
<script src="assets/ds.js" defer></script>

<!-- 2) 또는 아래 "Component CSS" 만 프로젝트 CSS 에 붙이고,
        :root 토큰은 Foundations › Design Token 에서 복사 -->
