Accordion

긴 설명 · 고급 설정 · FAQ 처럼 당장 보지 않아도 되는 정보를 접어 두었다가 필요할 때 펼칩니다. 핵심 정보와 필수 입력은 펼쳐 두고, 같은 층위의 화면 전환에는 Tab, 순서 진행에는 Steps 를 씁니다.

1. Default

Outline · md 가 기본이고, 처음에는 닫힌 상태로 둡니다. 사용자가 반드시 봐야 하는 첫 항목만 예외로 펼쳐 둡니다(open).

고급 탐지 옵션
휴리스틱 분석, 메모리 스캔, 스크립트 차단을 개별로 켜고 끕니다. 기본값은 모두 켬입니다.

2. Variant

Outline(기본)은 항목마다 테두리가 있는 카드로, 페이지 바탕 위에 씁니다. Flat 은 테두리 없이 구분선만 있어 카드 · 패널 안에 씁니다 — 바탕 · 테두리 · 좌우 여백은 .accordion-group.flat 이 그립니다.

Flat

Usage

React: @jiran/ds-react 패키지를 설치하고 style.css 를 한 번 import 하면 위 React 탭 코드를 그대로 쓸 수 있습니다(React Package). HTML: assets/style.css 를 연결하고(일부만 필요하면 아래 컴포넌트 CSS 복사), 동작이 필요하면 assets/ds.js 를 함께 넣습니다 — 이 페이지의 프리뷰가 그 스크립트로 동작합니다. 색은 전부 토큰(var(--surface-brand-primary) 등)을 참조하므로 --accent-* 만 제품 컬러로 바꾸면 됩니다.
