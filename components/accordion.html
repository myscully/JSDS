Accordion

긴 설명이나 고급 설정을 접어 두고 필요할 때 펼칩니다. 네이티브 details/summary 를 써 JS 없이 동작합니다.

완료Figma ↗DesktopHTML+CSS · React

Examples

1. Default

details.accordion > summary + .body. open 속성으로 초기 펼침.

고급 탐지 옵션 3개 설정
휴리스틱 분석, 메모리 스캔, 스크립트 차단을 개별로 켜고 끕니다. 기본값은 모두 켬입니다.
HTML
<details class="accordion" open style="max-width:560px">
  <summary>고급 탐지 옵션 <small>3개 설정</small></summary>
  <div class="body">휴리스틱 분석, 메모리 스캔, 스크립트 차단을 개별로 켜고 끕니다. 기본값은 모두 켬입니다.</div>
</details>

2. Group

여러 항목. 하나만 펼치려면 같은 name 을 줍니다(브라우저 지원 시).

정책은 언제 적용되나요?
배포 버튼을 누른 뒤 에이전트가 다음 체크인(최대 5분)에서 받아 적용합니다.
차단된 파일은 어디에 보관되나요?
격리 저장소에 30일 보관 후 자동 삭제됩니다.
예외 처리는 어떻게 하나요?
정책 › 예외 목록에서 해시 또는 경로를 등록합니다.

3. Flat / Disabled

카드 안에서는 보더 없는 .flat. 권한이 없으면 .disabled.

일반
정책 이름, 설명, 적용 그룹
스케줄
적용 요일과 시간대
감사 로그 권한 필요

<div class="accordion-group flat" style="max-width:560px;background:var(--bg-surface);padding:0 20px;border-radius:12px">

</div>

Props

HTML 에서는 클래스와 속성으로, React(@jiran/ds-react)에서는 같은 이름의 prop(variant · size …)으로 변형·상태를 지정합니다.

Prop / ClassType · ValuesDefaultDescription
details.accordioncontainer—summary + .body
openattribute—펼침 상태
nameattribute—같은 name 은 하나만 펼침
.flatbooleanfalse보더 없는 구분선형
.disabledbooleanfalse펼칠 수 없음
summary smallelement—우측 보조 정보

Usage

React: @jiran/ds-react 패키지를 설치하고 style.css 를 한 번 import 하면 위 React 탭 코드를 그대로 쓸 수 있습니다(React Package). HTML: assets/style.css 를 연결하고(일부만 필요하면 아래 컴포넌트 CSS 복사), 동작이 필요하면 assets/ds.js 를 함께 넣습니다 — 이 페이지의 프리뷰가 그 스크립트로 동작합니다. 색은 전부 토큰(var(--accent) 등)을 참조하므로 --accent-* 만 제품 컬러로 바꾸면 됩니다.

React @jiran/ds-react

npm i @jiran/ds-react

// main.tsx — 앱 진입점에서 한 번
import "@jiran/ds-react/style.css";

// 컴포넌트
import { Accordion, AccordionGroup } from "@jiran/ds-react";

HTML

<!-- 1) 토큰 + 전체 컴포넌트 스타일 한 번에 연결 -->
<link rel="stylesheet" href="assets/style.css">
<!-- 동작(드롭다운·탭·달력·표 정렬/선택·토스트 등) — 순수 JS 한 파일. React 제품은 불필요 -->
<script src="assets/ds.js" defer></script>

<!-- 2) 또는 아래 "Component CSS" 만 프로젝트 CSS 에 붙이고,
        :root 토큰은 Foundations › Design Token 에서 복사 -->
