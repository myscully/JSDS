Chip

필터 조건이나 입력된 값을 작은 캡슐로 보여줍니다. 선택 가능한 Filter Chip 과 삭제 가능한 Input Chip 을 구분합니다. 상태 표시는 Tag 를 씁니다.

언제 쓰는가
Filter Chip 은 목록을 좁히는 조건에, Input Chip 은 사용자가 입력한 값에 씁니다. 상태나 분류를 보여 주기만 하면 Tag 를 씁니다.
Placement
검색 아래 필터 행, 입력 필드 안 값 목록

Default

선택하지 않은 기본 칩입니다.

React · @jiran/ds-react
import { useState } from "react";
import { Chip, ChipGroup } from "@jiran/ds-react";

function Row({ items, color }: { items: string[]; color?: "brand" | "neutral" }) {
  const [sel, setSel] = useState(items.slice(0, 2));
  return (
    <ChipGroup clearable={sel.length > 0} onClear={() => setSel([])}>
      {items.map((l) => (
        <Chip key={l} color={color} selected={sel.includes(l)} onSelectedChange={(on) => setSel((s) => (on ? [...s, l] : s.filter((x) => x !== l)))}>{l}</Chip>
      ))}
    </ChipGroup>
  );
}

export default function Example() {
  return (
    <div style={{ display: "flex", flexDirection: "column", gap: 12 }}>
      <Row items={["Critical", "High", "Medium"]} />
      <Row items={["Windows", "macOS", "Linux"]} color="neutral" />
    </div>
  );
}

Rules

넘칠 때
한 줄을 넘으면 다음 줄로 내려갑니다. +N 으로 접지 않아 조건이 전부 보입니다
필터 초기화
필터 칩이 2개 이상이면 묶음 끝에 '필터 초기화'를 둡니다. 켜진 칩이 있을 때만 보이고, 누르면 포커스는 첫 칩으로 갑니다
지운 뒤 포커스
다음 칸으로, 없으면 앞 칸으로 옮깁니다. 칸이 하나도 남지 않으면 묶음 자신입니다
긴 값
값은 240px 에서 말줄임합니다. 지우기 버튼에 포커스가 오면 펼치고, 접근 이름에 전체 값이 들어갑니다. 마우스는 잘린 값에만 붙는 Tooltip 으로 봅니다(title 은 쓰지 않습니다)
형태와 색
형태는 Outline(기본, 회색 선)과 Solid(회색 면) 둘이고, 고른 칩은 두 형태 모두 같은 진한 면입니다. 색은 brand(기본, 제품 색 면)와 neutral(반전 면) 둘이며 고른 모양만 바꿉니다 — 고르지 않은 칩은 둘 다 중립입니다. 입력값 칩은 고를 수 없어 형태만 받고 색은 중립입니다
