Notification

시스템 상태와 결과를 알립니다. 페이지 안에 머무는 Notice, 잠시 떴다 사라지는 Toast, 화면 맨 위 전체 폭에 띄우는 공지 Banner 를 구분해 씁니다.

언제 쓰는가
사용자가 언제까지 봐야 하는지로 고릅니다. 방금 한 동작의 결과는 Toast, 화면 일부의 지속 상태는 Notice, 제품 전체에 영향을 주는 공지는 Banner 로 알리고, 응답을 받아야 진행하면 Popup 을 씁니다. 기준표는 Interaction 에 있습니다.
Placement
Notice 는 페이지 헤더 아래, Toast 우측 하단, Banner 헤더 위

Default

본문 안에 머무는 기본 인라인 알림입니다.

정책이 아직 배포되지 않았습니다변경 사항은 '배포'를 눌러야 에이전트에 적용됩니다.

Rules

Toast 시간
기본 4초, 실행 취소 같은 동작이 있으면 10초입니다. 마우스를 올리거나 포커스가 들어오면 묶음 전체의 시간이 멈춥니다.
오류 Toast
오류 Toast 는 닫을 때까지 남고 닫기 버튼이 있습니다. 표시 시간을 정해 줘도 사라지지 않습니다.
쌓임
동시에 3개까지입니다. 넘치면 자동으로 사라지는 것부터 지웁니다. 닫을 때까지 남는 오류는 밀리지 않으므로 3개를 넘을 수 있습니다.
같은 알림
동작이 없는 같은 문구는 쌓지 않고 시간을 다시 잽니다. 동작이 있으면 실행 취소 대상이 서로 달라 합치지 않습니다.
Banner
Banner 는 한 번에 하나만 둡니다. 닫으면 닫혔다는 이벤트가 나고, 다시 띄울지는 제품이 정합니다. 안의 버튼은 끄지 않습니다. 제품 색 면 위에서는 꺼진 글자가 보이지 않기 때문입니다. 할 수 없는 동작이면 버튼을 빼고 문구로 알립니다. 처리하는 동안 버튼에 로딩 표시를 하는 것은 괜찮습니다.
알리는 세기
화면 낭독기가 하던 말을 끊고 바로 읽는 알림은 바로 알아야 하는 위험에만 씁니다. Toast 는 읽던 말이 끝난 뒤에 읽힙니다.
문구
오류에는 원인과 다음 행동을 함께 적습니다. 폼 필드 오류는 Toast 로 알리지 않고 필드 아래에 적습니다.
