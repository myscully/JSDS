Number Input

임계치 · 세션 시간처럼 정확한 수를 입력합니다. 입력칸 안에 단위와 증감 버튼이 있고 위 · 아래 화살표로도 바꿉니다.

언제 쓰는가
크기를 비교하거나 더하는 수에 씁니다. 사번이나 포트 목록, 전화번호처럼 이름에 가까운 숫자는 Text Field 로 받고, 대략의 값을 빠르게 정하는 자리는 Slider 를 씁니다.
Placement
폼의 값 자리 · 정책 임계치

Default

단위 · 범위가 있는 기본 입력입니다. 범위 밖 값은 떠날 때 오류로 알립니다.

분
5분부터 1440분까지 입력할 수 있습니다.

Rules

범위 안내
받을 수 있는 범위를 도움말에 미리 적습니다.
범위 밖
입력을 막거나 값을 몰래 고치지 않습니다. 입력을 받고 떠날 때 오류로 알립니다. 폼에서는 저장을 막습니다.
단위
입력칸 안쪽 뒤에 둡니다. 스크린 리더도 값과 함께 읽습니다.
증감
버튼과 위 · 아래 화살표는 정한 간격만큼 움직이고 범위 끝에서 멈춥니다. 끝에 닿은 쪽 버튼은 꺼집니다.
키보드
증감 버튼은 Tab 에서 뺍니다. 화살표 키가 같은 일을 합니다.
표준 입력
브라우저의 표준 숫자 입력 위에 만듭니다. 숫자 입력은 전부 이 컴포넌트를 씁니다.
