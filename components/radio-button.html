Radio Button

여러 항목 중 정확히 하나를 고릅니다. 옵션이 5개를 넘으면 Select 를 씁니다.

언제 쓰는가
2~5개 중 하나를 고르고 보기가 모두 보여야 할 때 씁니다. 6개 이상이면 Select 를, 고르는 즉시 보기만 바뀌면 Select Button 을 씁니다.
Placement
폼의 배타 옵션, 설정의 동작 선택

Default

선택하지 않은 기본 상태입니다.
