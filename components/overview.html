Components

사용자 인터페이스를 구성하는 재사용 가능한 요소입니다.

모든 컴포넌트 페이지는 동작하는 라이브 프리뷰 + 복사 가능한 코드(HTML+CSS / React) + Props로 구성됩니다. 프리뷰의 드롭다운·탭·달력·표 정렬 등은 assets/ds.js(순수 JS)로, React 탭 코드는 @jiran/ds-react 로 같은 동작을 합니다. 스타일은 assets/style.css 하나로 동작하며, 색은 토큰(var(--surface-brand-primary) 등)만 참조합니다.
