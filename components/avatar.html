Avatar

사용자를 이니셜로 표시합니다. 사진은 지원하지 않습니다. 여러 사람은 Avatar Group 으로 겹쳐 놓고 넘친 수를 '외 N명' 으로 적습니다.

언제 쓰는가
사용자를 이니셜로 나타낼 때 씁니다. 눌러서 여는 사용자 메뉴가 필요하면 Top Navigation 의 사용자 메뉴를 씁니다.
Placement
Top Navigation 오른쪽 끝 · List 행 앞. Avatar Group 은 표의 담당자 칸 · 카드 헤더 · 상세 패널

Default

With Name

Rules

글자
이니셜 1~2자로 씁니다.
크기
목록 · 표 · 상단 바에는 기본이나 작은 크기를 씁니다. 큰 크기는 프로필처럼 한 사람을 보이는 자리에만 쓰고, Avatar Group 에는 쓰지 않습니다.
색
모든 아바타는 같은 중립 회색 면과 글자를 씁니다. 사람은 이니셜과 이름으로 가르고, 상태나 역할을 아바타 색으로 알리지 않습니다.
이름
옆에 이름이 보이면 아바타는 스크린 리더에서 숨깁니다. 혼자 있으면 이미지로 읽히게 하고 이름을 줍니다.
누를 때
그 자체로는 버튼이 아닙니다. 사용자 메뉴는 Top Navigation 의 사용자 메뉴를 씁니다.
Group
여러 사람은 Avatar Group 으로 겹쳐 놓습니다. 묶음에는 '담당자' 처럼 무엇의 사람들인지 알리는 이름을 주고, 아바타마다 이름을 줍니다.
Group 개수
아바타는 5개까지 보이고 나머지는 뒤에 '외 N명' 으로 적습니다. 전체 목록을 열어야 하면 '외 N명' 을 글자 버튼으로 두고, 목록은 제품이 그립니다.

Usage

React 제품은 디자인 시스템 패키지를 설치하고 스타일 파일을 한 번 불러오면 위 React 탭 코드를 그대로 쓸 수 있습니다. 설치 방법은 React Package 에 있습니다. HTML 제품은 공통 스타일 파일을 연결하고, 일부만 필요하면 아래 컴포넌트 CSS 를 복사합니다. 동작이 필요하면 동작 스크립트를 함께 넣습니다. 이 페이지의 미리보기도 그 스크립트로 움직입니다. 색은 모두 토큰을 따르므로 제품 색 하나를 고르면 나머지가 따라옵니다.
