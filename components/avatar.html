Avatar

사용자를 이니셜로 표시합니다. 사진은 지원하지 않습니다.

글자
이니셜 1~2자입니다. 빌드가 검사합니다.
이름
옆에 이름이 보이면 aria-hidden 입니다. 혼자 있으면 role="img" 와 aria-label 로 이름을 줍니다.
누를 때
그 자체로는 버튼이 아닙니다. 사용자 메뉴는 Top Navigation 의 .topbar-user 를 씁니다.

1. Size

32 와 .sm 24.

김김
HTML
<div style="display:flex;gap:12px;align-items:center"><span class="avatar" role="img" aria-label="김민준">김</span><span class="avatar sm" role="img" aria-label="김민준">김</span></div>
CSS · .avatar
/* JS Design System v0.8 · .avatar · 토큰(var(--*))은 assets/style.css :root 참고 */
.avatar{width:2rem;height:2rem;border-radius:50%;background:var(--surface-brand-subtle);color:var(--foreground-brand-primary);display:inline-grid;place-items:center;font-size:var(--font-size-12);font-weight:700;flex:none;line-height:max(1rem,16px);letter-spacing:0.0252em}
.avatar.sm{width:1.5rem;height:1.5rem;font-size:var(--font-size-11);line-height:max(0.875rem,14px);letter-spacing:0.0311em}
React · @jiran/ds-react
import { Avatar } from "@jiran/ds-react";

export default function Example() {
  return (
    <div style={{ display: "flex", gap: 12, alignItems: "center" }}>
      <Avatar initials="김" role="img" aria-label="김민준" />
      <Avatar initials="김" size="sm" role="img" aria-label="김민준" />
    </div>
  );
}

Props

HTML 에서는 클래스와 속성으로, React(@jiran/ds-react)에서는 같은 이름의 prop(variant · size …)으로 변형·상태를 지정합니다.

Prop / ClassType · ValuesDefaultDescription
.avatar
span—32. React initials
.sm
boolean
false
24. React size="sm"

Usage

React: @jiran/ds-react 패키지를 설치하고 style.css 를 한 번 import 하면 위 React 탭 코드를 그대로 쓸 수 있습니다(React Package). HTML: assets/style.css 를 연결하고(일부만 필요하면 아래 컴포넌트 CSS 복사), 동작이 필요하면 assets/ds.js 를 함께 넣습니다 — 이 페이지의 프리뷰가 그 스크립트로 동작합니다. 색은 전부 토큰(var(--surface-brand-primary) 등)을 참조하므로 --accent-* 만 제품 컬러로 바꾸면 됩니다.

React @jiran/ds-react

npm i @jiran/ds-react

// main.tsx — 앱 진입점에서 한 번
import "@jiran/ds-react/style.css";

// 컴포넌트
import { Avatar } from "@jiran/ds-react";

HTML

<!-- 1) 토큰 + 전체 컴포넌트 스타일 한 번에 연결 -->
<link rel="stylesheet" href="assets/style.css">
<!-- 동작(드롭다운·탭·달력·표 정렬/선택·토스트 등) — 순수 JS 한 파일. React 제품은 불필요 -->
<script src="assets/ds.js" defer></script>

<!-- 2) 또는 아래 "Component CSS" 만 프로젝트 CSS 에 붙이고,
        :root 토큰은 Foundations › Design Token 에서 복사 -->

복사본의 전제

아래 "Component CSS" 만 붙일 때는 이 규칙들과 Pretendard(assets/fonts) · :root 토큰을 전제로 그려집니다 — assets/style.css 의 값 그대로입니다. 앱에 같은 규칙이 있으면 넣지 않아도 됩니다.

*{box-sizing:border-box}
body{margin:0;background:var(--background-neutral-primary);color:var(--foreground-neutral-primary);font-family:var(--font-sans);font-size:var(--font-size-16);line-height:1.6;-webkit-font-smoothing:antialiased}
code,kbd{font-family:var(--font-sans);font-variant-numeric:tabular-nums}
