Command PaletteN, 새 항목

화면 이동과 자주 쓰는 작업을 키보드로 찾아 바로 실행합니다. 어느 화면에서든 같은 단축키로 엽니다.

언제 쓰는가
메뉴가 깊거나 자주 쓰는 작업이 여러 화면에 흩어져 있을 때 둡니다. 화면 안의 데이터를 찾는 일은 Search 로 합니다.
비슷한 것
폼 안에서 값을 골라 넣는 일은 Combobox 입니다.
Placement
화면 위쪽 가운데 · 여는 버튼 옆에 단축키를 함께 보임

Default

버튼이나 단축키로 엽니다. 글을 치면 걸러지고 Enter 로 실행합니다. 이 예제는 고른 명령을 알림으로 보입니다.

Rules

열기
맥은 Command K, 그 밖은 Ctrl K 로 엽니다. 입력칸에 글을 치는 중에도 열리고, 다시 누르면 닫힙니다. 다른 대화상자가 열린 동안에는 열지 않습니다.
찾기
이름과 다른 이름을 띄어쓰기 · 대소문자 없이 찾고, 자음만 치면 초성으로 찾습니다. 맞는 것이 없으면 다른 낱말을 권합니다.
키보드
포커스는 검색칸에 남고 위아래 화살표로 항목을 옮깁니다. Enter 로 실행하고 Esc 로 닫습니다.
항목
화면 이동과 작업을 묶어 보입니다. 항목 이름은 동사로 끝나는 동작이거나 화면 이름입니다. 단축키가 있으면 끝에 보입니다.
실행
실행하면 팔레트를 먼저 닫고, 포커스는 연 자리로 돌아갑니다. 되돌릴 수 없는 작업은 바로 실행하지 않고 확인 대화상자를 엽니다.
범위
지금 사용자가 할 수 있는 것만 보입니다. 권한이 없는 화면은 넣지 않습니다.
알림
결과 수는 화면 낭독기에 알립니다.
