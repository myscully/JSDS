Slider

범위 안의 값을 끌어서 고릅니다. 정확한 값이 중요하면 Number Input 을 씁니다.

언제 쓰는가
대략적인 값을 고를 때 씁니다. 정책 임계치처럼 숫자가 정확해야 하면 Number Input 을 먼저 씁니다.
Placement
정책 설정의 수치 항목. 정확 입력이 필요하면 Number Input 을 함께 둠

Default

트랙은 현재 값까지 채워 그립니다. 값을 코드로 바꿀 때는 채운 길이도 함께 바꿉니다.

Rules

숫자 입력을 함께 둘 때
트랙과 숫자 입력칸을 값 하나로 묶습니다. 입력칸은 트랙 오른쪽에 두고, 제출하는 값은 입력칸입니다. Slider 를 움직이면 입력칸이 바로 바뀝니다. 입력칸에 범위를 벗어난 값을 쓰면 글자는 지우지 않고 오류로 알리며, Slider 는 가까운 끝에 둡니다
단위
현재 값에 단위를 붙여 보이고, 스크린 리더도 값을 단위와 함께 읽게 합니다
범위
값은 하나입니다. 두 끝을 고르는 범위 슬라이더는 지원하지 않습니다. 시작 · 끝 값을 Text Field 둘로 받습니다

Usage

React 제품은 디자인 시스템 패키지를 설치하고 스타일 파일을 한 번 불러오면 위 React 탭 코드를 그대로 쓸 수 있습니다. 설치 방법은 React Package 에 있습니다. HTML 제품은 공통 스타일 파일을 연결하고, 일부만 필요하면 아래 컴포넌트 CSS 를 복사합니다. 동작이 필요하면 동작 스크립트를 함께 넣습니다. 이 페이지의 미리보기도 그 스크립트로 움직입니다. 색은 모두 토큰을 따르므로 제품 색 하나를 고르면 나머지가 따라옵니다.
