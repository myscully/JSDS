Data Visual

대시보드의 수치 · 추이 · 비율을 두 층으로 보여줍니다. 정적 요약(KPI · 스파크라인 · 가로 막대 · 도넛)은 CSS 만으로 그려 JS 없이 토큰이 먹고 Figma 와 1:1 입니다. 탐색형 차트(시계열 · 막대 · 도넛 · 혼합)는 축 · 툴팁 · 범례 토글이 필요할 때 Chart.js(MIT) 위에 토큰을 입혀 그립니다(assets/ds-chart.js · @jiran/ds-react/chart). 경계: 값 몇 개를 한눈에 요약하면 정적, 기간 · 비교 · 상호작용이 필요하면 탐색형입니다. 색은 심각도 토큰과 계열 토큰(--chart-series-1~6)만 씁니다.

탐색형 차트 — HTML assets/ds-chart.js + Chart.js

축 · 툴팁 · 시계열이 필요한 차트는 Chart.js(MIT) 위에 토큰을 입혀 그립니다. ds-chart.js 가 --chart-* · 심각도 토큰을 계산값으로 읽어 Chart.js 옵션을 만들고, 라이트/다크 전환과 제품 색 주입 때 다시 칠합니다. 프리셋은 timeseries · bar · donut · mixed 넷이고 결과는 보통의 Chart.js config 라 옵션을 덧붙일 수 있습니다.

<!-- Chart.js(MIT) 본체 + 테마 어댑터. 차트가 있는 페이지에만 -->
<script src="assets/vendor/chart.umd.js" defer></script>
<script src="assets/ds-chart.js" defer></script>

<!-- canvas[data-chart] + data-spec 은 DOMContentLoaded 때 자동으로 그려진다(이 페이지의 예제). 직접 그리려면: -->
<script>
  const handle = DSChart.mount(Chart, document.querySelector("#trend"), DSChart.presets.timeseries({
    labels: ["10-28", "10-29", "10-30"],
    series: [{ label: "Critical", tone: "critical", data: [12, 18, 9] }, { label: "High", tone: "high", data: [30, 24, 41] }],
    stacked: true,
  }));
  // handle.chart(Chart.js 인스턴스) · handle.repaint() · handle.destroy() — 테마 · 제품 색 전환은 자동으로 다시 칠한다
</script>
