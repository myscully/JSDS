File Upload

파일을 고르거나 끌어다 놓아 올립니다. 형식 · 용량 검사와 진행 표시까지 시스템이 맡고, 실제 전송은 제품이 합니다.

언제 쓰는가
인증서나 가져올 데이터처럼 파일을 받아 서버로 보낼 때 씁니다. 키나 토큰처럼 붙여 넣는 값은 Text Field 로 받습니다.
Placement
폼의 필드 자리 · 가져오기 대화상자

Default

파일 하나를 받습니다. 영역을 누르거나 끌어다 놓습니다. 이 예제의 전송은 흉내입니다.

import { useState } from "react";
import { Field, FileUpload, type UploadItem } from "@jiran/ds-react";

const MB = 1024 * 1024;

export default function Example() {
  const [items, setItems] = useState<UploadItem[]>([]);
  return (
    <Field label="인증서" help="PEM · CRT, 5MB 이하" style={{ width: "100%", maxWidth: 480 }}>
      <FileUpload accept=".pem,.crt" maxSize={5 * MB}
      items={items}
      onAdd={(added) => setItems((p) => [...p, ...added.map(({ id, file }) => ({ id, name: file.name, size: file.size, status: "uploading" as const, progress: 0 }))])}   // 여기서 전송을 시작합니다
      onRemove={(id) => setItems((p) => p.filter((x) => x.id !== id))}
      />
    </Field>
  );
}

const MB = 1024 * 1024;

export default function Example() {
  const [items, setItems] = useState<UploadItem[]>([]);
  return (
    <Field label="서명 파일" help="SIG, 1MB 이하" style={{ width: "100%", maxWidth: 480 }}>
      <FileUpload compact accept=".sig" maxSize={MB}
      items={items}
      onAdd={(added) => setItems((p) => [...p, ...added.map(({ id, file }) => ({ id, name: file.name, size: file.size, status: "uploading" as const, progress: 0 }))])}   // 여기서 전송을 시작합니다
      onRemove={(id) => setItems((p) => p.filter((x) => x.id !== id))}
      />
    </Field>
  );
}

import { Field, FileUpload, type UploadItem } from "@jiran/ds-react";

const MB = 1024 * 1024;

export default function Example() {
  const [items, setItems] = useState<UploadItem[]>([]);
  return (
    <Field label="예외 목록" help="CSV · TXT, 10MB 이하, 5개까지" style={{ width: "100%", maxWidth: 480 }}>
      <FileUpload multiple maxFiles={5} accept=".csv,.txt" maxSize={10 * MB}
      items={items}
      onAdd={(added) => setItems((p) => [...p, ...added.map(({ id, file }) => ({ id, name: file.name, size: file.size, status: "uploading" as const, progress: 0 }))])}   // 여기서 전송을 시작합니다
      onRemove={(id) => setItems((p) => p.filter((x) => x.id !== id))}
        onRetry={(id) => setItems((p) => p.map((x) => (x.id === id ? { ...x, status: "uploading", progress: 0 } : x)))}
      />
    </Field>
  );
}

Rules

안내
받는 형식과 용량을 도움말에 미리 적습니다. 빌드가 검사합니다.
거절
형식 · 용량 · 개수가 맞지 않으면 목록에 이름과 이유를 남깁니다. 통과한 파일은 그대로 받습니다.
전송 실패
다시 시도와 지우기를 둡니다. 거절된 파일은 다시 보내도 같으므로 지우기만 둡니다.
하나만 받을 때
새 파일을 고르면 바로 교체합니다.
전송 중 지우기
전송 중인 줄에도 지우기를 둡니다. 지우거나 교체하면 ds:upload-remove · React onRemove 가 나가고, 제품이 그 전송을 멈춥니다.
폼
전송 중이거나 오류가 있으면 제출을 막고 그 필드로 옮깁니다. 저장 버튼은 켜 둡니다.
모양
기본은 드롭 영역입니다. 파일 하나를 받는 좁은 폼 칸은 .compact 입니다. 버튼형도 드롭은 받습니다.
보안
화면의 형식 검사는 안내입니다. 서버에서 다시 검사합니다.
