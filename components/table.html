v0.8 · 지란지교시큐리티 기획팀 디자인파트

Table

정렬·선택이 필요 없는 단순 표입니다. 상세 정보(키-값), 비교표, 요약 통계에 씁니다.

용도
데이터 전용입니다. 레이아웃에 쓰지 않습니다
머리글
머리글 없는 표를 만들지 않습니다. 키-값 표는 th 가 머리글입니다. 빌드가 검사합니다
옮기는 기준
행이 많아 정렬 · 선택 · 페이지가 필요해지면 Data Table 입니다
행 스타일
가로선이 기본입니다. 긴 비교표는 .zebra, 숫자가 빽빽한 리포트는 열 사이 세로선 .grid, 5행 안팎의 요약은 선 없는 .plain 입니다. .plain 은 .zebra · .grid 와 함께 쓰지 않습니다(빌드가 검사합니다)
경계
바깥 테두리 · radius 가 없습니다. 위는 회색 헤더 면, 아래는 마지막 행 선이 경계입니다. 카드 안에 붙일 때는 카드 패딩을 없애고(.card.flush) 표를 그대로 둡니다
비슷한 것
한 대상의 속성은 키-값 표, 카드 안의 짧은 속성 몇 줄은 Card Meta, 같은 종류의 항목을 나열하면 List 입니다
