Pagination

긴 목록을 페이지로 나누어 이동합니다. 총 건수와 페이지 크기 선택을 함께 둡니다.

표시 개수
20 · 50 · 100 중에서 고릅니다. 개수나 필터가 바뀌면 1페이지로 돌아갑니다
번호 칸
화살표를 빼고 9칸 이하입니다. 빌드가 검사하고, React 는 넘으면 경고합니다
한 페이지뿐일 때
번호를 숨기고 건수는 남깁니다
이동한 뒤
data-target · target 을 주면 표 맨 위로 스크롤하고 포커스를 옮깁니다. 현재 페이지는 제품이 URL 에 남깁니다
끝을 모르는 목록
수십만 건 로그처럼 전체 쪽수를 세지 못하면 커서 방식(이전 · 다음)입니다. 끝이 확인되면 버튼을 끕니다
