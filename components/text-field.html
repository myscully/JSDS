Text Field

한 줄 텍스트를 입력합니다. 라벨 · 도움말 · 오류 메시지가 하나의 필드로 묶입니다.

언제 쓰는가
자유로운 글을 한 줄로 받을 때 씁니다. 정해진 값 가운데 고르게 하려면 Select 나 Combobox 를, 숫자는 Number Input 을, 날짜는 Date Picker 를 씁니다.

Rules

입력 전

라벨
모든 입력에 보이는 라벨을 위에 둡니다. placeholder 로 대신하지 않습니다. 로그인처럼 칸이 둘뿐이고 칸 안 아이콘이 뜻을 보태는 화면만 라벨을 숨기고 placeholder 로 보입니다. 숨긴 라벨은 스크린 리더가 읽습니다
Placeholder
입력 예시만 짧게 씁니다. 입력을 시작하면 사라지므로 형식 · 조건은 도움말에 씁니다
필수
필수 항목이 있는 폼은 맨 위에 * 필수 항목 안내를 둡니다

검증

오류
동작은 Interaction › Input errors 를 따릅니다. 폼에 검증을 켜면 시스템이 처리합니다. 문구는 Writing 대로 무엇이 일어났는지와 고치는 법을 씁니다
글자 수
한도가 있고 넘기기 쉬운 필드에만 카운터를 둡니다. 붙여넣은 값이 잘리지 않도록 넘겨도 입력되고, 오류로 알립니다
포커스 링
포커스를 받았거나 열린 필드의 링은 제품 색입니다. 빨강인 제품1과 주황인 브랜드만 중립색입니다. 빨강은 오류 링과, 주황은 경고색과 헷갈리지 않게 하려는 것입니다. 오류 필드의 링은 어느 제품에서나 빨강입니다

상태와 종류

Disabled · Read-only
Disabled 는 고칠 수 없고 값도 중요하지 않을 때, Read-only 는 고칠 수 없지만 값을 읽고 복사해야 할 때 씁니다
필드 안 조작
필드 안에 버튼을 넣지 않습니다. 비밀번호 표시 · Date Picker 달력 · Search 지우기 · Combobox 태그 제거만 예외입니다
입력 종류
IP · URL · 해시도 본문 글자로 씁니다. 고정폭 글자는 Code 에만 씁니다. 비밀번호는 표시 토글을 둡니다. 표준 입력 종류와 자동 완성 값을 쓰고, 비밀번호 필드의 붙여넣기를 막지 않습니다
아이콘
입력칸 안 앞에 둔 아이콘은 무엇을 넣는 칸인지 빨리 알아보게 돕는 장식입니다. 라벨을 대신하지 않아 라벨은 그대로 위에 둡니다
Textarea
세로로만 늘립니다
인증 코드
자리 수가 정해진 숫자 코드는 자리마다 칸을 나눠 받습니다. 숫자가 아닌 글자는 받지 않고, 붙여넣기와 문자 코드 자동 채우기는 모든 칸을 한 번에 채웁니다. 다 채워도 저절로 제출하지 않습니다
