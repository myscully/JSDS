v0.8 · 지란지교시큐리티 기획팀 디자인파트

Text Field

한 줄 텍스트를 입력합니다. 라벨·도움말·오류 메시지가 하나의 필드 단위로 묶입니다.

라벨
모든 입력에 보이는 라벨을 위에 둡니다. placeholder 로 대신하지 않습니다
Placeholder
입력 예시만 짧게 씁니다. 입력을 시작하면 사라지므로 형식 · 조건은 도움말에 씁니다
필수
필수 항목이 있는 폼은 위에 .form-legend 로 * 필수 항목 을 표시합니다
오류
동작은 Interaction › Input errors 를 따릅니다. 폼에 data-validate 를 달면 시스템이 처리합니다. 문구는 Writing 대로 무엇이 일어났는지와 고치는 법을 씁니다
글자 수
한도가 있고 넘기기 쉬운 필드에만 카운터를 둡니다. 붙여넣은 값이 잘리지 않도록 넘겨도 입력되고, 오류로 알립니다
Disabled · Read-only
Disabled 는 고칠 수 없고 값도 중요하지 않을 때, Read-only 는 고칠 수 없지만 값을 읽고 복사해야 할 때 씁니다
필드 안 조작
필드 안에 버튼을 넣지 않습니다. 비밀번호 표시 · Date Picker 달력 · Search 지우기 · Combobox 태그 제거만 예외입니다
입력 종류
IP · URL · 해시는 .mono 로 고정폭, 비밀번호는 표시 토글을 둡니다. 표준 type · autocomplete 값을 쓰고, 비밀번호 필드의 붙여넣기를 막지 않습니다
Textarea
세로로만 늘립니다

1. Default / Error

오류 시 .error 를 필드에 붙이고 help 를 오류 메시지로 바꿉니다. 원인과 해결 방법을 함께 씁니다.

Usage

React: @jiran/ds-react 패키지를 설치하고 style.css 를 한 번 import 하면 위 React 탭 코드를 그대로 쓸 수 있습니다(React Package). HTML: assets/style.css 를 연결하고(일부만 필요하면 아래 컴포넌트 CSS 복사), 동작이 필요하면 assets/ds.js 를 함께 넣습니다 — 이 페이지의 프리뷰가 그 스크립트로 동작합니다. 색은 전부 토큰(var(--surface-brand-primary) 등)을 참조하므로 --accent-* 만 제품 컬러로 바꾸면 됩니다.
