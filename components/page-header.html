Page Header

페이지 맨 위에서 이 화면이 무엇인지와 주요 동작을 보여 줍니다.

제목
페이지 제목은 h1 이고 화면에 하나입니다. 하나인지는 빌드가 검사합니다. 메뉴 이름과 같게 씁니다.
Breadcrumb
첫 칸에 넣습니다. 제목 바로 위 8px 입니다.
설명
.sub 는 ID · 범위 · 갱신 시각처럼 짧은 정보 한 줄입니다.
동작
3개까지입니다. 주 버튼은 하나이고 오른쪽 끝입니다. 나머지는 Dropdown 으로 묶습니다. 빌드가 검사합니다.
긴 제목
제목 칸에서 줄바꿈합니다. 동작은 오른쪽 위에 남습니다.
