Item Tile

아이콘·제목·설명을 담은 작은 선택지입니다. 연동 모듈이나 보호 기능처럼 여러 개를 고르거나, 눌러서 바로 이동할 때 씁니다.

언제 쓰는가
아이콘이 앞서는 작은 선택지를 여러 개 고르거나, 눌러서 바로 이동할 때 씁니다.
비슷한 것
하나만 고르면 Card Radio 를, 내용이 많은 카드를 고르면 Card Selection 을 씁니다.
Placement
연동 목록, 여러 개를 고르는 모듈 선택

Default

선택하지 않은 기본 타일입니다.

Rules

선택의 뜻
타일의 선택은 하나씩 켜고 끄는 다중 선택입니다. 하나만 고르는 묶음에는 쓰지 않습니다.

Spec

PropertyValue
Size최소 폭 180 · padding 16 · 아이콘 36
Containerradius/lg 8 · line/neutral/secondary · 선택 brand
Label제목 14 Bold · 설명 12 Regular tertiary

Usage

React 제품은 디자인 시스템 패키지를 설치하고 스타일 파일을 한 번 불러오면 위 React 탭 코드를 그대로 쓸 수 있습니다. 설치 방법은 React Package 에 있습니다. HTML 제품은 공통 스타일 파일을 연결하고, 일부만 필요하면 아래 컴포넌트 CSS 를 복사합니다. 동작이 필요하면 동작 스크립트를 함께 넣습니다. 이 페이지의 미리보기도 그 스크립트로 움직입니다. 색은 모두 토큰을 따르므로 제품 색 하나를 고르면 나머지가 따라옵니다.
