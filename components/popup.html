Popup

사용자의 확인이나 짧은 입력을 받아야 진행할 때 화면 위에 띄우는 모달입니다. 되돌리기 어려운 동작 앞에 둡니다. 목록을 보며 내용을 확인하려면 Side Panel 을 씁니다.

언제 쓰는가
응답을 받아야 진행할 수 있을 때만 씁니다. 자주 띄우면 흐름을 끊습니다. 큰 표나 가로 스크롤, 여러 단계 이동이 필요하면 넣지 않고 별도 페이지로 보냅니다.
Placement
화면 중앙. 열리면 안으로 포커스를 옮기고, 닫으면 연 요소로 돌려보냅니다

Default

제목 · 본문 · 액션으로 이루어진 기본 구성입니다.

Rules

닫기
헤더의 닫기 버튼은 꼭 둡니다. Esc 와 취소 버튼으로도 닫힙니다. 입력하는 중이거나 위험 확인이면 배경을 눌러도 닫지 않습니다. 입력한 뒤 Esc · 닫기 · 취소로 닫으려 하면 바로 닫지 않고 팝업 안에서 버릴지 묻습니다. 포커스는 '계속 편집' 에 놓습니다.
첫 포커스
열 때 닫기 버튼과 위험한 실행 버튼은 건너뜁니다. 입력칸이 있으면 입력칸에, 없으면 취소 버튼에 포커스를 놓습니다.
주 버튼
주 버튼의 이름은 제목의 동작을 그대로 씁니다. '정책을 배포할까요?' 의 주 버튼은 '확인' 이 아니라 '배포' 입니다.
처리 중
처리하는 동안 주 버튼에 로딩 표시를 하고, 닫기 버튼 · 취소 · Esc · 배경 누름으로 닫는 길을 모두 막습니다. 실패하면 팝업을 그대로 두고 안에 오류를 보입니다. 입력한 내용을 잃지 않게 하려는 것입니다.
위험 확인
위험 확인은 제목을 위험 색으로 칠하고, 화면 낭독기에 경고 대화상자로 알립니다. 확인 문구를 입력받는 것은 복구할 수 없고 대량일 때만 둡니다. 모두 확인받으면 습관적으로 넘기게 됩니다. 삭제 버튼은 끄지 않고, 누르면 문구를 검사해 다르면 입력칸 아래에 고치는 법을 적습니다.
긴 본문
본문만 스크롤하고 제목과 버튼은 그 자리에 둡니다.
폭
폭은 기본 440px 입니다. 넓은 640px 은 필드가 두 열이거나 미리보기를 함께 보여 줄 때만 씁니다.
겹침
모달 위에 모달을 띄우지 않습니다.
