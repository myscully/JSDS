v0.9 · 지란지교시큐리티 기획팀 디자인파트

Changelog

버전별 변경 이력입니다. 가이드와 Figma 파일의 버전을 함께 올립니다.

버전날짜내용
v0.92026-11-15컴포넌트를 하나씩 정비하고 공통 정책을 세웠습니다. Foundations 에 Interaction · Writing 페이지를 더하고, 컴포넌트 페이지를 정의 · 고르기 표 · 예제 · Rules · Spec · Props · Usage 순서로 맞췄습니다. 새 컴포넌트는 Combobox · Side Panel · Steps · Form · Empty State · Page Header · Avatar · Link · File Upload · Code · Copy Field · Number Input · Time Picker · Tree · Notification Center 입니다. 입력 검증, 표의 밀도와 행 펼침, 기간 선택과 시각 입력, 글자 크기 체계와 텍스트 스타일 19단계, 제품 색 팔레트 여섯, 한 톤으로 맞춘 Data Visual 세트를 더했습니다. 패턴은 컴포넌트 페이지와 같은 순서로 맞추고 정비한 컴포넌트로 다시 지었으며, 상세 화면 · 권한과 역할 · API 키와 비밀값 · 사고 처리 · 오류와 권한 없음 · 위험 작업 확인 · 가져오기와 내보내기 · 로그인과 세션 · 일괄 작업 진행 · 보고서와 예약 발송 · 감사 로그와 변경 이력 · 알림 규칙 패턴을 더했습니다. 마지막으로 전체 코드를 점검해 오류와 쓰지 않는 코드를 정리하고, 모든 페이지의 설명을 지금 동작에 맞게 다시 썼습니다.
v0.82026-10-20컬러 시스템을 전면 개편했습니다. 의미 토큰을 여섯 그룹(foreground · background · surface · line · effect · static)으로 값과 이름까지 바꾸고, Atomic 램프 13개는 숫자가 클수록 밝은 체계로 통일했습니다. Brand 는 제품이 넣는 다섯 단계 색이고, 제품 색 위의 흰 글자가 4.5 대비를 넘어야 합니다. Colors 페이지를 Semantic 과 Atomic 탭으로 다시 짜고 브랜드 역할 맵을 그 안으로 합쳤습니다. React 패키지 0.8.0 은 깨지는 변경이라 마이그레이션 문서를 함께 냈습니다.
v0.62026-09-09Foundations 를 Overview 와 Base material(Colors · Elevation · Grid · Icons · Typography)로 다시 짰습니다. Colors 는 Semantic 과 Atomic 탭에 라이트 · 다크 값을 보여 주고, Elevation 은 그림자 종류와 단계 표를, Grid 는 아트보드 · 브레이크포인트 · 간격 · 12 컬럼 레이아웃을, Icons 는 검색되는 Outline · Filled 갤러리를, Typography 는 기본 규칙 · 줄바꿈 · 스타일 표를 담았습니다. Radius · Motion · Accessibility · 토큰 원본은 Resources › Design Token 으로 옮겼습니다.
v0.52026-09-08React 컴포넌트 패키지를 더했습니다. 컴포넌트와 패턴 30개를 동작과 접근성까지 갖춘 React 컴포넌트로 만들고, 사이트의 React 탭을 패키지를 쓰는 코드로 바꿨습니다. 사이트 HTML 과 React 의 구조가 같은지 테스트합니다. 아이콘을 한 세트로 통일하고 Resources › React Package 페이지를 열었습니다. 사이트의 모든 미리보기를 실제로 동작하게 하는 순수 JS 스크립트도 더했습니다. HTML+CSS 로 쓰는 제품은 이 파일 하나로 같은 동작을 얻습니다.
v0.42026-09-07코드 중심 가이드로 바꿨습니다. 컴포넌트 30개와 패턴 11개에 라이브 미리보기, 복사할 수 있는 HTML+CSS · React 코드, Props 표를 붙였습니다. 컴포넌트 CSS 는 한 블록으로 모아 페이지마다 필요한 부분만 뽑아 보여 줍니다. Foundations 에 토큰 복사 블록을 더하고, Figma 의 Components · Patterns 페이지에도 코드 스펙과 같은 변형 프레임을 놓았습니다.
v0.32026-09-04정보 구조와 레이아웃을 다시 짰습니다. 상단 메뉴(Home · Foundations · Components · Patterns · Resources)와 섹션 메뉴를 두고, 데스크톱 기준의 컴포넌트 문서 틀을 만들었습니다. 컬러 모델은 회색 기반에 제품 색 자리와 회사 브랜드 색을 더한 구성으로 정리했습니다.
v0.22026-09-03디자인 가이드라인을 반영했습니다. 무채색 바탕과 상태색을 정하고, 여백을 넉넉히 하며, 테두리를 줄이고 그림자로 구획을 나눴습니다. 표의 행 높이 · hover · 정렬 아이콘을 정했습니다.
v0.12026-09-03틀을 만들었습니다. Figma 파일의 페이지 · 변수 · 텍스트와 이펙트 스타일 · 섹션, 그리고 제품 가이드의 골격입니다.
