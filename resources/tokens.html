Token Download

CSS 변수와 JSON 형식으로 토큰을 내려받습니다.

Design Token 페이지에서 CSS 전체를 복사할 수 있고, 빌드 산출물 _build/components.json 에 토큰(light/dark)과 컴포넌트 스펙·예제 코드가 함께 들어 있습니다. JSON(Style Dictionary) 예시:

{
  "color": { "accent": { "600": { "value": "{product.main}" } }, "brand": { "500": { "value": "#FF7F00" } } },
  "space": { "4": { "value": "16px" } }, "radius": { "md": { "value": "8px" } }
}

Figma Variables → JSON 내보내기 연동은 예정입니다.
