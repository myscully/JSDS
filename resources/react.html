React Package

@jiran/ds-react — 이 가이드의 46개 컴포넌트와 패턴 래퍼를 실제 React 컴포넌트로 구현한 패키지입니다. 사이트와 같은 클래스 마크업을 렌더링하므로 스타일시트 하나로 동작하고, 각 컴포넌트 페이지의 React 탭 코드가 곧 사용법입니다.

0.8.0 은 깨지는 변경입니다. 컬러 토큰을 의미 층째 값·이름까지 교체했습니다 — dist/style.css 의 변수 이름이 전부 바뀝니다. 마크업과 props 는 그대로이므로 토큰을 직접 참조하지 않는 제품은 패키지만 올리면 됩니다. 전환표는 패키지의 MIGRATION.md 와 Foundations › Colors 에 있습니다. applyAccent() 의 주입 단계는 10개에서 5개(--prod-40~60)로 바뀌었습니다.

설치

npm i @jiran/ds-react

// main.tsx — 앱 진입점에서 한 번
import "@jiran/ds-react/style.css";   // 토큰 + 컴포넌트 CSS (사이트 크롬 제외)
import { ToastProvider, applyProductColor } from "@jiran/ds-react";

applyProductColor("red");            // 제품 색 팔레트 키(blue · red · cyan · navy · orange · neutral · ai) → --prod-40~60 · data-accent

createRoot(document.getElementById("root")!).render(
  <ToastProvider>
    <App />
  </ToastProvider>,
);
테마
<html data-theme="dark"> 또는 setTheme("dark"). 없으면 시스템 설정을 따릅니다. 포털(Popup·Toast)도 <html> 에서 토큰을 상속합니다
서체·배경
앱 루트에 .ds-root 를 붙이면 Pretendard · 본문 색 · 배경 토큰이 적용됩니다. 기본 글자는 Body 2/Reading(15/24)로 사이트 본문(16px/1.6)과 다르지만 컴포넌트는 크기·줄 높이를 스스로 정해 같은 배치로 그려집니다 — Pagination 의 생략 기호 · Dropdown · 심각도 셀만 놓인 곳의 글자 크기를 따릅니다
브라우저
color-mix() 사용 — Chrome 111+ · Safari 16.2+ · Firefox 113+
버전
패키지 major.minor 는 이 가이드 버전(v0.9)과 같이 올립니다

사용

모든 컴포넌트는 forwardRef · className 병합 · 나머지 props 전달을 지원합니다. 변형은 HTML 클래스와 같은 이름의 prop 입니다.

import { Button, TextField, Tag, DataTable, useToast } from "@jiran/ds-react";

function PolicyForm() {
  const toast = useToast();
  return (
    <form onSubmit={(e) => { e.preventDefault(); toast.show("정책이 저장되었습니다"); }}>
      <TextField label="정책 이름" required help="2~40자" />
      <Tag tone="critical">Critical</Tag>
      <Button type="submit" size="md" variant="solid" color="primary">정책 저장</Button>
    </form>
  );
}

동작·접근성

  • Dropdown/Select: 바깥 클릭·Esc 닫힘, 닫힌 트리거에서 ↑↓ 로 열기, ↑↓ Home End 이동, 글자로 항목 찾기, Tab 은 닫고 다음 칸으로, aria-haspopup/expanded, role=listbox|menu
  • Combobox: 포커스는 입력에, aria-activedescendant, 입력 필터, Enter 선택, Esc 닫기, 여러 개는 태그 · Backspace 제거, 결과 · 선택을 role=status 로 알림
  • Esc: 켜진 것 중 가장 안쪽 하나만 닫힙니다(Popup 안의 Select 는 Select 먼저)
  • Tabs: ←→ Home End, roving tabIndex, aria-selected/controls
  • Popup: Portal + 배경, 포커스 트랩/복원, Esc, role=dialog aria-modal aria-labelledby, 입력한 뒤 닫으면 안에서 버릴지 물음(confirmDiscard)
  • ToastProvider/useToast: 우측 하단 스택, 자동 소멸(기본 4초 · 동작이 있으면 10초), 오류는 닫을 때까지 남음, 동시에 3개까지 — 넘치면 자동으로 사라지는 것부터 지우고 오류는 밀리지 않아 3개를 넘을 수 있음, aria-live=polite
  • DatePicker/Calendar: Text Field 입력 하나에 YYYY. MM. DD 자동 형식 · ↑↓ 조각 이동, 단위 연 · 월 · 일, 단일 · 기간(두 달), data-locale 로 제목 · 요일 · 월 · 접근 이름을 Intl 로 표기, data-timezone 기준 시간대(dayjs), 제목으로 연 → 월 이동, min/max(달력은 막고 키보드 입력은 오류로 알림), 프리셋, 유효하지 않은 값 상태(data-validity · aria-invalid + 원인 · 고치는 법), 하단 버튼(오늘 · 초기화 · 취소 · 적용) · 즉시 적용, role=dialog aria-modal + role=grid 날짜 격자 — ←→ ↑↓ PageUp/Down Home/End, Esc 는 그 피커만 닫고 필드로 포커스
  • DataTable: 정렬(aria-sort) · 선택(헤더 indeterminate) · 행 액션 · 빈 상태
  • Checkbox/Radio/Switch/Slider/Accordion: 네이티브 요소 그대로(키보드·스크린리더 기본 지원)

React 를 쓰지 않는 제품: assets/ds.js

HTML+CSS 탭 코드를 그대로 쓰는 제품은 assets/style.css 와 함께 assets/ds.js(순수 JS · 의존성 없음 · 약 237KB)를 넣으면 이 사이트의 프리뷰와 같은 동작을 얻습니다. Date Picker 의 기준 시간대(data-timezone)를 쓸 때만 dayjs(MIT) 와 utc · timezone 플러그인을 ds.js 와 함께 싣습니다 — 사이트는 assets/vendor/dayjs.min.js · dayjs.utc.js · dayjs.timezone.js 를 Date Picker 가 있는 페이지에만 싣습니다. 클래스 마크업에 이벤트 위임으로 동작을 붙이므로 서버 렌더링·동적 추가 마크업에도 그대로 적용됩니다(동적으로 넣은 마크업의 초기 상태 동기는 DS.init(root)).

<link rel="stylesheet" href="assets/style.css">

  document.addEventListener("ds:select", e => console.log(e.detail.value)); // 이벤트는 문서에서 듣습니다 — 전체 목록은 아래 이벤트 표
