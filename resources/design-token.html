Design TokenN

이 가이드가 쓰는 토큰 원본(CSS 변수 · Light/Dark)과 Radius · Motion · Accessibility 규칙입니다. --accent-* 만 제품 컬러로 바꾸면 나머지는 그대로 씁니다. 색의 의미와 사용 규칙은 Foundations › Colors 를 참고하세요.

완료

Token Layers

Primitive
--gray-* --brand-* --accent-* --red-*… 값의 원천. 컴포넌트에서 직접 쓰지 않음 (Colors › Atomic)
Semantic
--bg-* --text-* --fill-* --line-* --border-* --accent --danger --sev-*… 컴포넌트는 이것만 참조 (Colors › Semantic)
제품 적용
제품 메인 컬러 HEX 하나로 --accent-50~900을 생성(명도 전개) → 나머지 토큰은 공통

Motion

전환·피드백 애니메이션의 지속 시간과 이징입니다. 컴포넌트 CSS 는 --motion-* 토큰만 참조하고, prefers-reduced-motion 일 때 모든 전환을 제거합니다.

토큰값용도
--motion-fast120ms ease-outhover, 토글, 체크
--motion-base200ms ease-in-out드롭다운, 툴팁, 프로그레스
--motion-slow320ms cubic-bezier(.2,.8,.2,1)팝업, 드로어

CSS

:root {
  --motion-fast: 120ms ease-out;
  --motion-base: 200ms ease-in-out;
  --motion-slow: 320ms cubic-bezier(.2,.8,.2,1);
}
.switch input{transition:background var(--motion-fast)}
.popup{animation:popup-in var(--motion-slow)}
@keyframes popup-in{from{opacity:0;transform:translateY(8px) scale(.98)}to{opacity:1;transform:none}}
@media (prefers-reduced-motion:reduce){*{transition:none!important;animation:none!important}}

Accessibility

WCAG 2.1 AA 를 기준으로 합니다.

  • 텍스트 대비 4.5:1, 대형 텍스트·UI 요소 3:1. Gray 500 이상만 텍스트에 사용
  • 모든 인터랙션 키보드 접근, 포커스 링 항상 표시(:focus-visible 2px --border-focus)
  • 색만으로 상태를 전달하지 않음(태그 라벨, 아이콘 병행)
  • 클릭 타깃 최소 32px
  • 동적 알림은 aria-live, 아이콘 전용 버튼은 aria-label
:focus-visible{outline:2px solid var(--border-focus);outline-offset:2px}
.sr-only{position:absolute;width:1px;height:1px;padding:0;margin:-1px;overflow:hidden;clip:rect(0,0,0,0);white-space:nowrap;border:0}

Accent 스케일 생성 (JS)

제품 메인 컬러 HEX 하나로 --accent-50~900 을 만들어 :root 에 주입합니다.

function hexToHsl(hex){const n=parseInt(hex.slice(1),16);const r=((n>>16)&255)/255,g=((n>>8)&255)/255,b=(n&255)/255;const mx=Math.max(r,g,b),mn=Math.min(r,g,b);let h=0,s=0;const l=(mx+mn)/2;if(mx!==mn){const d=mx-mn;s=l>.5?d/(2-mx-mn):d/(mx+mn);switch(mx){case r:h=(g-b)/d+(g<b?6:0);break;case g:h=(b-r)/d+2;break;default:h=(r-g)/d+4;}h/=6;}return [h*360,s*100,l*100];}
function hslToHex(h,s,l){s/=100;l/=100;const k=n=>(n+h/30)%12;const a=s*Math.min(l,1-l);const f=n=>l-a*Math.max(-1,Math.min(k(n)-3,Math.min(9-k(n),1)));return "#"+[f(0),f(8),f(4)].map(x=>Math.round(x*255).toString(16).padStart(2,"0")).join("").toUpperCase();}
export function accentScale(hex){const [h,s]=hexToHsl(hex);const L={50:96,100:90,200:80,300:68,400:56,500:46,700:30,800:22,900:14};const out={};for(const [k,l] of Object.entries(L)) out[k]=hslToHex(h,Math.min(100,s*(k<300?0.7:1)),l);out[600]=hex.toUpperCase();return out;}
export function applyAccent(hex){for(const [k,v] of Object.entries(accentScale(hex))) document.documentElement.style.setProperty("--accent-"+k,v);}
