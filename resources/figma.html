Variables · Styles

  • Primitive: color/atomic/{cool-neutral·neutral·blue·green·orange·red·lime·cyan·light-blue·violet·purple·pink·red-orange}/{step}, space/{n}, radius/{name}, size/{card-padding…}
  • Semantic(Light/Dark): color/semantic/{foreground·background·surface·line·effect·static}/{하위}/{이름} — CSS 변수 이름과 1:1 입니다(color/semantic/surface/brand/heavy ↔ --surface-brand-heavy)
  • Text Styles Pretendard — 저장소는 19단계(= .t-* 클래스), Figma 는 사이트가 완성된 뒤 한 번에 맞춥니다 · Effect Styles Shadow Normal xs~xl · Spread sm/md(= --shadow-*, 1~3 은 별칭)

작업 규칙

  • 색은 Semantic 변수만, 글자는 Text Style만, 그림자는 Effect Style만.
  • Variant 속성명은 소문자(variant / size / state). 사이트 Props 표의 클래스 이름과 같게.
  • 컴포넌트 Description에 용도·사용 규칙과 사이트 페이지 링크 기입.
