Variables · Styles

  • Primitive: color/{gray·accent·red·amber·emerald·sky}/{step}, color/brand/{step}, space/{n}, radius/{name}, size/{card-padding…}
  • Semantic(Light/Dark): bg/ text/ border/ primary(=Accent)/ status/ severity/ — CSS 변수 이름과 1:1
  • Text Styles 14단계 Pretendard(= .t-* 클래스) · Effect Styles Shadow Normal xs~xl · Spread sm/md(= --shadow-*, 1~3 은 별칭)

작업 규칙

  • 색은 Semantic 변수만, 글자는 Text Style만, 그림자는 Effect Style만.
  • Variant 속성명은 소문자(variant / size / state). 사이트 Props 표의 클래스 이름과 같게.
  • 컴포넌트 Description에 용도·사용 규칙과 사이트 페이지 링크 기입.
