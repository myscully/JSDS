Contribution

새 컴포넌트를 제안·검토·배포하는 절차입니다.

이 문서는 아직 작업 중입니다. 아래 절차는 큰 흐름이며, 각 단계의 서식과 기준이 확정되면 이 페이지를 갱신합니다.

  1. 제안: 필요 배경, 기존 컴포넌트로 안 되는 이유, 사용 화면 캡처
  2. 디자인 리뷰: 디자인파트 검토(토큰 준수, 변형·상태 완비, 접근성)
  3. 구현 리뷰: 개발팀 검토(Props 명세, 반응형, 키보드)
  4. 배포: _build/components.data.js 에 예제·Props 추가 → style.src.css 의 Live component samples 블록에 CSS 추가 → 재빌드 → Figma 섹션 갱신 → Changelog 기록
