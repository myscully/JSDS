로그인 · 세션

관리 콘솔에 들어오는 로그인과 2단계 인증, 오래 쓰지 않은 세션의 만료 안내입니다. 실패 이유와 남은 횟수를 알리고, 입력한 값은 지우지 않습니다.

언제 쓰는가
관리 콘솔에 로그인하거나, 2단계 인증 코드를 받거나, 세션이 곧 끝난다고 알릴 때 씁니다.
비슷한 패턴
로그인 뒤 처음 하는 설정은 온보딩으로, 권한이 없는 화면은 오류 화면으로 보여 줍니다.

Composition

이 패턴이 조합하는 컴포넌트입니다. 세부 옵션은 각 컴포넌트 페이지에 있습니다.

Rules

실패 안내
아이디와 비밀번호 중 무엇이 틀렸는지는 알리지 않고, 둘 중 하나가 맞지 않는다고 적습니다. 잠금까지 남은 횟수와 잠기는 시간을 함께 씁니다.
입력 유지
실패해도 아이디는 남기고 비밀번호만 비웁니다. 포커스는 비밀번호 칸으로 옮깁니다.
자동 완성
아이디와 비밀번호, 일회용 코드 칸에 맞는 자동 완성 속성을 줘 비밀번호 관리자와 문자 코드 채우기가 동작하게 합니다.
비밀번호 보기
비밀번호 칸에는 보기 버튼을 둡니다. 붙여넣기를 막지 않습니다.
2단계 인증
숫자 6자리를 Text Field 의 인증 코드 칸 여섯에 한 자리씩 받습니다. 붙여넣기와 자동 채우기는 칸을 나눠도 한 번에 채워집니다. 다 채워도 저절로 제출하지 않고 확인 버튼을 누르게 합니다.
세션 만료
끝나기 2분 전에 대화상자로 알리고 남은 시간을 보여 줍니다. 시간 세기와 연장은 제품 서버가 맡고, 시간이 다 되면 로그인 화면으로 보낸 뒤 원래 화면으로 돌아오게 합니다.
