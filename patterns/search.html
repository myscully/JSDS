검색

검색과 필터로 결과 목록을 조회하는 화면입니다. 조건은 늘 보이게 두고, 결과 수와 적용 중인 조건을 함께 보여 줍니다.

언제 쓰는가
이벤트나 단말, 정책처럼 많은 항목에서 조건으로 좁혀 찾는 목록 화면에 씁니다.
비슷한 패턴
초 단위로 쌓이는 로그를 훑는 화면은 로그 뷰어를 씁니다.

Composition

이 패턴이 조합하는 컴포넌트입니다. 세부 옵션은 각 컴포넌트 페이지에 있습니다.

Rules

툴바
검색칸 옆에 필터와 기간을 두고 되도록 한 줄에 놓습니다. 옆 컨트롤은 제 폭을 지키고 검색칸이 남는 폭을 가집니다. 자리가 모자라면 검색칸이 최소 폭까지 줄고, 그래도 넘칠 때만 줄을 바꿉니다. 한 줄에 놓인 컨트롤은 같은 높이로 맞추고, 동작 버튼은 결과 줄 오른쪽 끝에 둡니다.
필터
여러 값을 고르는 필터는 Combobox 로 받습니다. 대시보드처럼 다른 화면에서 넘어온 조건은 결과 줄에 Chip 으로 보여 주고, 하나씩 지울 수 있게 합니다.
결과 줄
결과 수를 툴바 아래 첫머리에 적습니다. 조건을 하나라도 바꿨으면 필터 초기화를 둡니다.
빈 결과
결과가 없으면 표 대신 Empty State 를 두고, 무엇을 바꾸면 되는지와 필터 초기화를 함께 보여 줍니다.
갱신
글자를 칠 때마다 조회하면 입력을 잠시 기다렸다가 조회합니다. 결과 수가 바뀌면 화면 읽기 프로그램에도 알립니다.
