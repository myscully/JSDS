가져오기 · 내보내기

목록을 파일로 한 번에 들여오거나 내보내는 화면입니다. 가져오기는 줄마다 검사해 결과를 보여 준 뒤 실행하고, 내보내기는 형식과 범위를 정해 받습니다.

언제 쓰는가
단말이나 사용자, 예외 목록처럼 수십 건 이상을 한 번에 넣거나 꺼낼 때 씁니다.
비슷한 패턴
한 건씩 넣는 것은 입력 폼을, 파일 하나를 첨부하는 것은 File Upload 를 씁니다.

Composition

이 패턴이 조합하는 컴포넌트입니다. 세부 옵션은 각 컴포넌트 페이지에 있습니다.

Rules

가져오기 순서
파일을 올리면 먼저 줄마다 검사하고, 결과를 보여 준 뒤 사용자가 가져오기를 누를 때 실행합니다. 올리자마자 바로 반영하지 않습니다.
검사 결과
전체 줄 수와 오류 줄 수를 Notice 에 적고, 오류 줄만 표로 보여 줍니다. 줄 번호와 값, 고치는 법을 함께 적습니다.
부분 가져오기
오류가 있어도 올바른 줄만 가져올 수 있게 합니다. 주 버튼에 가져올 줄 수를 적고, 오류 줄은 파일로 내려받아 고칠 수 있게 합니다.
양식
가져오기 영역 옆에 열 이름이 맞는 양식 파일을 둡니다. 허용하는 형식과 용량은 도움말에 적습니다.
내보내기
형식과 기간을 대화상자에서 고릅니다. 기간이 길어 오래 걸리면 예약해서 보내고, 끝나면 알림으로 알립니다.
개인정보
개인정보가 들어간 열은 기본으로 빼고, 넣으려면 따로 체크하게 합니다. 내보낸 기록은 감사 로그에 남깁니다.
