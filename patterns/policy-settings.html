정책 설정

정책과 시스템을 설정하는 화면입니다. 섹션마다 카드를 두고, 왼쪽에 라벨과 설명, 오른쪽에 컨트롤이 있는 행을 쌓습니다. 바로 적용되는 Switch 와 배포해야 적용되는 입력을 구분합니다.

언제 쓰는가
정책 하나의 동작이나 시스템 설정처럼, 언제든 돌아와 값을 바꾸는 설정 화면에 씁니다.
비슷한 패턴
처음 한 번 순서대로 정하는 설정은 온보딩으로, 새 항목을 만드는 입력은 입력 폼으로 받습니다.

배포 전 변경
배포하지 않은 변경이 있으면 맨 위 경고 알림에 건수를 적습니다. 화면을 떠나려 하면 버릴지 묻습니다.
컨트롤 고르기
켜고 끄기는 Switch, 정도는 Slider, 정확한 수는 Number Input, 시각은 Time Picker, 여럿 고르기는 Combobox 로 받습니다.
적용 대상
부서처럼 계층이 있는 대상은 지금 고른 것을 Tag 로 보여 주고, 바꿀 때는 Side Panel 의 체크박스 Tree 에서 고릅니다.
연결 정보
에이전트 등록 키처럼 복사해 쓰는 값은 Copy Field 로 보여 줍니다.
