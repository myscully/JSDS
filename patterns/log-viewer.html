로그 뷰어

대량 로그를 빠르게 훑고 필터링하는 화면입니다. Compact 표 + 모노스페이스 시간/IP + 심각도 태그 + 실시간/일시정지 전환.

완료Figma ↗Security ConsoleHTML+CSS · React

Composition

이 패턴이 조합하는 컴포넌트입니다. 세부 옵션은 각 컴포넌트 페이지를 참고하세요.

SearchChipSelect ButtonData TableTagPaginationButton
밀도
.tbl.compact 44px 행, 시간·IP 는 .log-row 모노스페이스
필터
심각도 Chip 다중 선택 + 검색 + 실시간/일시정지
상세
행 클릭 → 우측 패널(표는 그대로)
