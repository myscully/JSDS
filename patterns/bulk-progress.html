일괄 작업 진행

여러 대상에 같은 작업을 한 번에 실행하고 끝날 때까지 지켜보는 화면입니다. 얼마나 진행됐는지와 실패한 대상을 보여 주고, 실패한 대상만 다시 실행합니다.

언제 쓰는가
정책 배포나 에이전트 업데이트처럼 수십 대 이상에 같은 작업을 실행하고, 끝나기까지 몇 분 이상 걸릴 때 씁니다.
비슷한 패턴
실행하기 전에 영향 범위를 확인하는 것은 위험 작업 확인을, 파일로 목록을 들여오는 것은 가져오기 · 내보내기를 씁니다.

Composition

이 패턴이 조합하는 컴포넌트입니다. 세부 옵션은 각 컴포넌트 페이지에 있습니다.

Rules

진행 표시
전체 수와 끝난 수를 함께 적고 진행 막대로 보여 줍니다. 남은 시간은 잴 수 있을 때만 적습니다.
성공과 실패
성공, 실패, 남은 수를 따로 셉니다. 실패가 생기면 작업이 끝나기 전에도 실패 수를 보여 줍니다.
화면을 떠나도 계속
작업은 서버에서 이어집니다. 사용자가 다른 화면으로 가도 멈추지 않고, 끝나면 알림 센터로 알립니다.
취소
취소는 아직 시작하지 않은 대상만 멈춥니다. 이미 끝난 대상은 되돌리지 않는다고 버튼 옆에 적습니다.
실패 목록
끝나면 실패한 대상과 이유를 표로 보여 줍니다. 실패한 대상만 다시 실행하는 버튼을 두고, 실패 목록은 파일로도 내려받게 합니다.
읽어 주기
진행 수가 바뀔 때마다 읽지 않습니다. 처음 실패했을 때와 끝났을 때만 화면 읽기 프로그램에 알립니다.
