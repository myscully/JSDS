# Mail Security Console — 데모

JS Design System 으로 만든 사내 메일 보안 솔루션 관리자 화면 세 장입니다. 제품 색은 팔레트의 제품1(빨강 `#C30D2A`)입니다.

| 파일 | 화면 |
| --- | --- |
| `login.html` | 로그인 → 2단계 인증(코드 6칸) → 대시보드로 이동 |
| `dashboard.html` | KPI 넷 · 일별 수신/차단 추이 · 위협 유형 분포 · 요일별 차단 · 차단 상위 발신 도메인 · 최근 위협 메일 |
| `spam.html` | 검색 · 판정 필터 · 기간, 선택 + 액션 바(정상 메일로 해제 · 발신자 차단 · 영구 삭제), 행 펼침 상세, 페이지 이동 |

## 여는 법

브라우저로 `login.html` 을 바로 엽니다(서버 필요 없음). 저장소의 `../../assets/` 를 상대 경로로 불러오므로 폴더를 옮길 때는 `assets/` 도 함께 옮깁니다.

- 로그인: 이메일 형식 + 비밀번호 4자 이상이면 통과합니다(4자 미만은 실패 안내 흉내). 2단계 코드는 숫자 6자리면 무엇이든 됩니다.
- 상단 바의 해 · 달 버튼으로 라이트/다크를 바꾸고, 선택은 `localStorage` 의 `msc-theme` 에 남습니다.

## 파일

- `gen.js` — 세 HTML 을 만드는 생성기입니다. 내용을 고치려면 이 파일을 고친 뒤 `node _demo/mail-security/gen.js` 를 돌립니다(HTML 을 직접 고치면 다음 생성 때 덮입니다).
- `demo.css` — 이 데모에만 필요한 보충(스팸 표 칸 폭 · 긴 제품 이름용 상단 바 왼쪽 폭). 앱 틀은 `assets/templates.css`, 컴포넌트는 `assets/style.css` 를 그대로 씁니다.
- `demo.js` — 제품 서버가 할 일의 흉내(로그인 흐름 · 액션 바 처리 + Toast · 테마 저장). 검증 · 선택 · 펼침 · 정렬 · Combobox · Date Picker · 사이드 내비 접힘 · 알림 센터는 `assets/ds.js` 가 합니다.

## 제품 색 적용

사이트 셸 스크립트(`app.js`)는 불러오지 않습니다 — 사이트에서 저장한 제품 색으로 덮기 때문입니다. 대신 각 HTML 의 `<html>` 에 직접 적습니다.

```html
<html lang="ko" data-accent="red"
      style="--prod-40:#980A21;--prod-45:#B00C26;--prod-50:#C30D2A;--prod-55:#DB0F2F;--prod-60:#F34B65">
```

`data-accent="red"` 덕분에 빨강 제품 규칙(입력 포커스 링은 중립, 오류 링은 빨강)이 그대로 걸립니다. `--prod-60` 은 다크 테마 글자가 4.5:1 을 넘도록 밝힌 값입니다.

## 알려 둔 것

- 콘솔 화면이라 최소 폭 1024 기준입니다. 390 폭에서는 화면이 가로로 스크롤합니다.
- 1280 미만에서는 사이드 내비가 자동으로 접힙니다. 1440 미만에서는 스팸 표가 표 영역 안에서 가로로 스크롤합니다.
- 데이터 · 도메인은 모두 `*.example` 계열의 예시입니다.
