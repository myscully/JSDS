디자이너N, 새 항목

Figma 에서 이 시스템으로 화면을 그리는 다섯 단계입니다. 라이브러리를 켜고, 인스턴스의 속성을 바꾸고, 색과 글자는 이름 있는 스타일로만 칠합니다.

라이브러리 켜기

작업할 Figma 파일을 열고 왼쪽 Assets 패널의 책 모양 아이콘에서 JS Design System 라이브러리를 켭니다. 한 번 켜 두면 그 파일에서 계속 쓸 수 있습니다.

왜라이브러리를 켜야 원본 컴포넌트가 고쳐질 때 내 화면도 따라 고쳐집니다.

해보기새 Figma 파일에서 라이브러리를 켜고 Assets 검색창에 Button 을 입력해 보세요.

인스턴스 넣고 속성 바꾸기

Assets 에서 컴포넌트를 캔버스로 끌어다 놓으면 인스턴스가 됩니다. 인스턴스를 고르면 오른쪽 패널에서 변형 · 크기 · 상태를 바꿀 수 있고, 그 이름은 사이트 컴포넌트 페이지의 Props 표와 같습니다.

왜인스턴스를 떼어 내면 원본이 고쳐져도 따라오지 않습니다. 시스템에 없는 모양이 필요하면 떼어 내지 말고 제안합니다.

3 / 5 단계

색 · 글자 · 그림자는 스타일로

채우기와 선은 Variables 탭의 변수로 칠합니다. 변수는 글자 · 바탕 · 면 · 선 · 효과 갈래로 나뉘어 있습니다. 글자는 텍스트 스타일, 그림자는 이펙트 스타일을 씁니다.

왜직접 고른 색은 다크 테마와 제품 색을 따라가지 않습니다. 변수로 칠한 화면은 모드만 바꾸면 다크와 다른 제품 색을 바로 볼 수 있습니다.

해보기그린 화면에서 변수에 묶이지 않은 색이 남아 있는지 찾아 가장 가까운 변수로 바꿔 보세요.

4 / 5 단계

템플릿 틀에서 시작

새 화면은 기준 프레임인 너비 1440 에서 시작합니다. Templates 에 비슷한 화면이 있으면 그 구성을 따라 상단 바 · 사이드 내비 · 머리글 · 본문 순서로 놓고, 폭과 여백은 Grid 페이지의 값을 씁니다.

왜같은 틀에서 시작하면 내비 폭과 여백이 제품마다 어긋나지 않습니다.

5 / 5 단계

넘기기 전 점검

정상 화면 말고도 빈 화면 · 불러오는 중 · 오류 · 비활성 상태를 그렸는지 봅니다. 화면 설명에는 레이어 이름 대신 컴포넌트 이름과 속성 값을 적습니다.

왜개발자는 Props 표의 이름으로 코드를 찾습니다. 상태가 다 그려져 있으면 개발 중에 다시 묻지 않습니다.

해보기내 화면에 쓴 컴포넌트 셋을 UI Dictionary 에서 찾아 React 이름이 무엇인지 확인해 보세요.
