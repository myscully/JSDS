Getting startedN

이 디자인 시스템은 제품 메인 컬러를 제외한 모든 기본 구성(색 · 글자 · 간격 · 컴포넌트 · 패턴)을 제공합니다. 역할에 맞는 탭을 골라 순서대로 따라 하면 됩니다.

완료Figma ↗Figma · React · HTML+CSSv0.6

누구에게 무엇이 필요한가

디자이너 · 기획자
Figma 라이브러리 + 이 사이트. 설치할 것이 없습니다
React 개발자
@jiran/ds-react 패키지 하나
HTML+CSS 개발자
assets/style.css + assets/ds.js 두 파일
  1. Figma 파일 열기JS Design System Figma 파일 ↗ — 페이지 구성(Home · Foundations · Components · Patterns · Resources)은 이 사이트와 같습니다. 어느 페이지에 무엇이 있는지는 Figma Library 표를 참고하세요.
  2. 내 디자인 파일에서 라이브러리 켜기작업할 파일을 열고 왼쪽 Assets 패널 → 책 모양(Libraries) 아이콘 → JS Design System 을 켭니다. 한 번 켜 두면 그 파일에서 계속 쓸 수 있습니다.
  3. 컴포넌트 넣기Assets 검색창에 이름(예: Button, Tag, Data Table)을 입력하고 캔버스로 끌어다 놓습니다. 넣은 것은 인스턴스라 원본은 바뀌지 않고, 원본이 갱신되면 따라서 갱신됩니다.
  4. 변형·상태 바꾸기인스턴스를 선택하면 오른쪽 패널에 variant · size · state 드롭다운이 보입니다. 이름은 이 사이트 각 컴포넌트 페이지의 Props 표와 같아서, 개발자와 같은 말로 이야기할 수 있습니다.
  5. 색·글자·그림자는 스타일만직접 색을 고르지 말고 채우기 → Variables 탭에서 bg/ text/ border/ primary/ status/ severity/ 변수를 씁니다. 글자는 Text Style, 그림자는 Effect Style. 이렇게 해야 제품 컬러·다크 테마가 자동으로 맞춰집니다.
  6. 이 사이트에서 확인하기같은 이름의 컴포넌트 페이지에서 Examples 로 실제 동작과 상태를, Props 표로 허용되는 변형을 확인합니다. 헤더의 Accent 선택으로 제품별 컬러를, 테마 버튼으로 다크 모드를 미리 볼 수 있습니다. 필요한 컴포넌트가 없으면 Contribution 절차로 제안합니다.

사이트 둘러보기: 상단 메뉴 Foundations(색·글자·간격 규칙) → Components(30개) → Patterns(11개 화면 패턴). 키보드 / 를 누르면 검색창으로 이동합니다.

  1. 패키지 설치 + 앱 진입점 설정스타일시트를 한 번 import 하고, 토스트를 쓰려면 앱을 ToastProvider 로 감쌉니다. applyAccent 에 제품 메인 컬러 HEX 하나를 넣으면 나머지 색은 자동입니다.
    npm i @jiran/ds-react

// main.tsx — 앱 진입점에서 한 번
import "@jiran/ds-react/style.css";   // 토큰 + 컴포넌트 CSS
import { ToastProvider, applyAccent } from "@jiran/ds-react";

applyAccent("#0B4171");               // 제품 메인 컬러 → --accent-50~900 생성

createRoot(document.getElementById("root")!).render(
  <ToastProvider>
    <App />
  </ToastProvider>,
);
  2. 컴포넌트 가져다 쓰기각 컴포넌트 페이지의 React 탭 코드가 곧 사용법입니다. 변형은 HTML 클래스와 같은 이름의 prop 입니다. 전체 목록은 React Package › 컴포넌트 ↔ 클래스.
    import { Button, TextField, Tag } from "@jiran/ds-react";

<TextField label="정책 이름" required />
<Tag tone="critical">Critical</Tag>
<Button size="md" variant="primary">정책 저장</Button>
  3. 테마·서체다크 테마는 html 요소의 data-theme 로 정하고(또는 setTheme("dark")), 앱 루트에 .ds-root 를 붙입니다.
    <!-- 다크 테마: html 요소에 지정. 없으면 시스템 설정을 따릅니다 -->
<html data-theme="dark">
<!-- 앱 루트에 .ds-root 를 붙이면 서체·본문 색·배경 토큰이 적용됩니다 -->
<div id="root" class="ds-root"></div>
  4. 확인패키지는 React 18 · 19, TypeScript, ESM · CJS 를 지원하고 color-mix() 를 쓰므로 Chrome 111+ · Safari 16.2+ · Firefox 113+ 가 필요합니다. 패키지 버전의 major.minor 는 이 가이드 버전(v0.6)과 같습니다. 자세한 내용은 React Package.
  1. assets 폴더 복사저장소 ↗의 assets/style.css · assets/ds.js · assets/fonts/ 세 가지를 함께 프로젝트에 넣습니다. style.css 가 fonts/PretendardVariable.woff2 를 상대 경로로 참조하므로 폴더 구조를 유지하세요.
  2. HTML 에 연결스타일시트 한 줄, 동작 스크립트 한 줄입니다. ds.js 는 의존성 없는 순수 JS 로 드롭다운·탭·달력·표 정렬·토스트 등을 붙여 줍니다.
    <!-- assets/ 폴더(style.css · ds.js · fonts/)를 프로젝트에 복사한 뒤 -->
<link rel="stylesheet" href="assets/style.css">
<script src="assets/ds.js" defer></script>
  3. 컴포넌트 페이지에서 복사원하는 컴포넌트 페이지에서 예제 아래 코드 보기 → 복사. 전체 CSS 대신 일부만 쓰려면 같은 곳의 Component CSS 와 Design Token 의 :root 토큰만 가져갑니다.
    <!-- 컴포넌트 페이지 HTML+CSS 탭에서 복사한 마크업을 그대로 붙입니다 -->
<button class="btn md primary">정책 저장</button>
<span class="tag critical">Critical</span>

<!-- 동작이 필요한 곳은 ds.js 의 API -->
<script>
  DS.toast("저장되었습니다");
  DS.popup.open("#confirm-delete");
  DS.init(document.getElementById("dynamic-area")); // 동적으로 넣은 마크업
</script>
  4. 확인이 사이트의 모든 프리뷰가 같은 style.css + ds.js 로 동작하므로, 사이트에서 되는 것은 제품에서도 그대로 됩니다. 이벤트(ds:select · ds:tab 등)와 API 는 React Package › assets/ds.js 를 참고하세요.

공통: 제품 컬러 적용

모든 색은 토큰을 참조하므로 --accent-* 열 단계만 제품 메인 컬러로 바꾸면 나머지는 그대로 씁니다. 그 외 토큰(무채색 · 상태색 · 간격 · 반경)은 제품이 달라도 공통입니다.

React
applyAccent("#0B4171") 한 줄. 런타임에 --accent-50~900 을 생성해 :root 에 넣습니다
HTML+CSS
아래처럼 :root 에 덮어씁니다. HEX 하나로 10단계를 만드는 함수는 Design Token › Accent 스케일 생성
미리보기
이 사이트 헤더의 Accent 선택으로 각 제품 컬러가 적용된 모습을 볼 수 있습니다. 실제 제품 컬러는 _build/data.js 의 PRODUCTS 에 등록합니다
브랜드
#FF7F00(--brand)은 회사 브랜드 강조에만. 제품 메인 컬러를 대신하지 않습니다
/* 제품 메인 컬러 하나로 생성한 10단계를 :root 에 덮어씁니다 (생성 함수는 Design Token › Accent 스케일 생성) */
:root{
  --accent-50:#EEF4FA; --accent-100:#D6E3F1; --accent-200:#ADC7E3; --accent-300:#7FA8D2; --accent-400:#4F86BC;
  --accent-500:#2A669E; --accent-600:#0B4171; --accent-700:#09365E; --accent-800:#072A49; --accent-900:#051E34;
}

문제가 생기면

글자가 기본 서체로 보임
assets/fonts/ 가 함께 복사됐는지, 서버에 .woff2 MIME(font/woff2)이 등록돼 있는지 확인
색이 일부 안 나옴
color-mix() 를 쓰므로 Chrome 111+ · Safari 16.2+ · Firefox 113+ 필요
다크 테마가 안 됨
data-theme="dark" 는 body 가 아니라 html 요소에
드롭다운·탭이 안 움직임
ds.js 가 defer 로 로드됐는지 확인. 나중에 넣은 마크업은 DS.init(요소) 한 번 호출
필요한 컴포넌트가 없음
Contribution 절차(제안 → 디자인 리뷰 → 구현 리뷰 → 배포)로 요청
